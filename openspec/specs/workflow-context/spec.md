# workflow-context Specification

## Purpose

定义板块 A（多 Agent 工作流）与板块 B（知识库管理系统）之间的唯一耦合点：新建任务时从知识库搜索并勾选资料（可精确到文档章节/片段），任务持久化资料引用并在 Agent 执行时作为只读上下文注入，让产出有据可依；知识库未配置时任务流程不受影响。

## Requirements

### Requirement: 任务关联知识库资料
系统 SHALL 在新建任务流程中提供「关联知识库资料」步骤：用户可从知识库搜索并勾选资料（文档或文档内章节/片段，最多 6 份）作为任务的输入材料。

#### Scenario: 勾选资料
- **WHEN** 用户在知识库中搜索并勾选 2 份资料（含 1 个章节片段）
- **THEN** 勾选的资料出现在任务输入的已选列表，含文档标题与片段摘要

#### Scenario: 超过数量上限
- **WHEN** 用户尝试勾选第 7 份资料
- **THEN** 系统提示已达上限（6 份）并阻止继续勾选

#### Scenario: 取消勾选
- **WHEN** 用户移除已勾选的某份资料
- **THEN** 该资料从任务输入中移除

### Requirement: 关联持久化与可见
系统 SHALL 将任务关联的资料引用（文档路径、标题、片段范围）随任务持久化，并在任务详情中可见可追溯。

#### Scenario: 任务详情查看关联资料
- **WHEN** 用户打开一个已关联资料的任务详情
- **THEN** 展示关联的资料列表（标题、路径、片段范围），并可跳转到知识库阅读原文

### Requirement: 注入 Agent 上下文
Agent 执行任务的相关阶段时，系统 SHALL 将关联资料的内容（按所选片段范围截取）注入其上下文，与既有 skills/files 注入通道一致；资料以只读方式使用，任务执行不写回知识库。

#### Scenario: 资料注入生成
- **WHEN** 文案 Agent 执行一个已关联资料的任务
- **THEN** 其上下文包含所选资料片段内容，产出可引用资料事实

#### Scenario: 关联资料缺失降级
- **WHEN** 任务关联的资料文件在 Vault 中已不存在（被移动/删除）
- **THEN** 任务照常执行，注入上下文以「资料缺失」提示代替，并在任务详情中标记该资料失效

### Requirement: 与工作流独立
知识库未连接时，新建任务流程 SHALL 正常可用：资料选择步骤显示「知识库未连接」提示并允许跳过，任务创建与 Agent 执行完全不受影响。

#### Scenario: 知识库未连接时新建任务
- **WHEN** Vault 未配置或未连接，用户新建任务
- **THEN** 任务创建流程与既有行为完全一致，资料选择显示未连接提示并可跳过，不产生错误
