## MODIFIED Requirements

### Requirement: 知识库页顶部紧凑总览带

系统 SHALL 在知识库页「已连接」状态的页面顶部、既有三栏浏览区之上，横向渲染一条紧凑总览带。总览带 SHALL 遵循「1 个核心指标 + 3 个可点入口」的信息构成：**一个**核心指标（近期被任务引用的待处理资料）与**三个**通往下一步操作的入口（灵感库 / 小助理 / 全部文档）。总览带 SHALL NOT 以并列技术计数卡的形式呈现文档数 / 标签数 / 目录数 / 关联边数——这些属于数据库统计，对运营决策无直接价值；其中确有决策价值的计数 SHALL 以内联文字形式并入对应入口，而非独立卡片。总览带内的「最近更新」区域 SHALL 以收窄的紧凑排布呈现。既有三栏（目录与标签 / 文档列表 / 阅读区）的结构与交互 SHALL 保持不变，其中**左侧目录栏 SHALL 支持折叠与展开**，折叠后文档列表区自动获得释放出的横向空间。

总览带的小助理入口 SHALL 渲染小助理的**真实 Agent 卡**（与工位卡同组件形态：头像 + 状态点 + 名字 + 角色），SHALL 位于总览带**右侧**（在「全部文档」入口之后），SHALL NOT 居中；该入口 SHALL 支持**收起与展开**（与工位栏一致的交互语义：收起后为紧凑一行，可再展开），收起态由前端记忆（页面会话内保持）。

#### Scenario: 总览带呈现一个核心指标与三个入口
- **WHEN** 知识库已连接且总览带渲染
- **THEN** 总览带呈现一个核心指标与三个可点入口，且不出现四张并列的技术计数卡

#### Scenario: 总览带数值与总览统计一致
- **WHEN** 知识库已连接且 `knowledgeStats()` 返回文档数 N、标签数 T、目录数 D、关联边数 E
- **THEN** 总览带内出现的任何计数均取自 `knowledgeStats()`，与接口返回一致，且不存在硬编码占位数字

#### Scenario: 入口可点击并到达对应视图
- **WHEN** 用户点击总览带中的某个入口
- **THEN** 系统切换到该入口对应的视图或面板，且入口自身显示与其相关的数量信息（如待整理条数）

#### Scenario: 小助理入口位复用工位 Agent 卡
- **WHEN** 小助理实体存在且总览带渲染
- **THEN** 小助理位展示其真实 Agent 卡（与工位卡同组件形态：头像 + 状态点 + 名字 + 角色），位于总览带右侧而非中间，点击可打开其设置弹窗

#### Scenario: 小助理位可收起与展开
- **WHEN** 用户收起总览带的小助理位，或再次展开
- **THEN** 收起后该位变为紧凑形态（一行），展开后恢复完整 Agent 卡；页面会话内该状态被记忆；两种状态下入口都不呈现为不可用的死链

#### Scenario: 三栏浏览行为不回归
- **WHEN** 总览带已渲染，用户点击某个目录节点、再点击某个标签、再点击某篇文档
- **THEN** 文档列表按该目录（含子目录）筛选、按该标签筛选、阅读区渲染该文档正文，三栏行为与升级前完全一致

#### Scenario: 最近更新收窄呈现
- **WHEN** 总览带渲染且「最近更新」存在多条条目
- **THEN** 该区域以收窄的紧凑宽度呈现，不挤压同行的核心指标与入口

#### Scenario: 左侧目录栏可折叠
- **WHEN** 用户点击左侧目录栏的折叠控件
- **THEN** 目录栏收起，文档列表区横向扩展，并保留一个可重新展开的控件；再次点击后目录栏恢复原宽度与浏览范围

#### Scenario: 索引进行中不阻塞界面
- **WHEN** `knowledgeStats().indexing` 为真
- **THEN** 总览带显示「索引中」状态并在索引完成后自动刷新为最新数值，期间三栏浏览与搜索仍可正常使用

#### Scenario: 未连接时不渲染总览带
- **WHEN** Vault 未配置或路径无效（`status.state === 'disconnected'`）
- **THEN** 知识库页仍渲染既有「未连接 Obsidian Vault」空状态与「连接 Obsidian Vault」按钮，不渲染总览带，且板块 A 全部功能照常可用

## REMOVED Requirements

### Requirement: 星图缩略预览
**Reason**: P1 已按用户验收的方案把总览带压缩为「1 个核心指标 + 3 个可点入口」，总览带内的星图缩略预览卡片已从界面移除（用户进入星图的入口保留在左栏「知识星图」导航，未受损）。P1 归档时该需求的移除被同步脚本错误吞掉、未走正式 REMOVED 流程，本轮补记。能力本体（完整可交互的知识星图）由 `knowledge-graph` 能力承载，不受影响。
**Migration**: 无需迁移——用户进入星图的既有入口（左栏导航）保持不变；原缩略卡提供的「点击进入星图」由左栏导航承接。
