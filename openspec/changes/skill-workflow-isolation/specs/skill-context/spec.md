## ADDED Requirements

### Requirement: 技能注入的工作流分类隔离
系统 SHALL 为挂载技能的 prompt 注入建立**工作流分类边界**：以单一映射表 `WORKFLOW_CATEGORIES` 定义每个工作流可使用的技能分类（电商工作流 `ecom-new-listing` → `['电商','通用']`；小红书工作流 `xhs-note` → `['小红书','通用']`）。组装 producer 最终 system prompt 时，Agent 挂载技能中**分类不在该任务工作流映射范围内**的条目 SHALL NOT 被注入（过滤 SHALL 发生在读取技能全文之前）；未在映射表中列出的 workflowId SHALL 全分类可见（兜底，防止新增工作流的技能被静默丢弃）。分类为「通用」的技能 SHALL 对所有工作流可用。系统 SHALL NOT 引入「显式跨域挂载」标记——隔离边界严格由技能分类决定。

#### Scenario: 电商任务不注入小红书技能
- **WHEN** 某 Agent 同时挂载了「小红书合规违禁词清单」（分类：小红书）与「电商文案模板」（分类：电商），其电商工作流任务（`ecom-new-listing`）进入产出
- **THEN** 最终 system prompt 的【挂载技能】段包含「电商文案模板」全文，不包含「小红书合规违禁词清单」

#### Scenario: 小红书任务不注入电商技能
- **WHEN** 该 Agent 的小红书工作流任务（`xhs-note`）进入产出
- **THEN** 【挂载技能】段包含「小红书合规违禁词清单」语义上等价的内容（经工作流专属通道）与小红书/通用分类的挂载技能，不包含「电商文案模板」

#### Scenario: 通用技能跨工作流可用
- **WHEN** Agent 挂载了分类为「通用」的技能（如「素材结构化」），任一工作流任务进入产出
- **THEN** 【挂载技能】段包含该技能全文

#### Scenario: 未知工作流兜底全可见
- **WHEN** 某任务的 workflowId 不在 `WORKFLOW_CATEGORIES` 映射表中
- **THEN** 该任务不执行分类过滤，Agent 全部挂载技能照常注入（兜底语义）

#### Scenario: 过滤发生在读取全文之前
- **WHEN** 组装【挂载技能】段时某挂载技能的分类不在映射范围内
- **THEN** 系统不读取该技能的文件内容（不产生无效 IO 与 token 消耗）

### Requirement: 工作流专属技能强制追加不受过滤影响
工作流专属技能（现 `WORKFLOW_SKILLS`：小红书合规违禁词清单 → `xhs-note`）SHALL 继续按既有机制**强制追加注入**到所属工作流的任务 prompt（独立段落【工作流专属技能】），SHALL NOT 受挂载分类过滤影响、SHALL NOT 要求用户挂载、SHALL NOT 占用 Agent 个人技能位。既有行为不回归。

#### Scenario: 合规清单持续注入
- **WHEN** 小红书工作流任务进入文案产出，无论各 Agent 挂载了什么技能
- **THEN** 最终 system prompt 包含【工作流专属技能】段及「小红书合规违禁词清单」内容（与既有行为一致）

#### Scenario: 电商任务无专属技能段
- **WHEN** 电商工作流任务进入产出
- **THEN** 最终 system prompt 不包含【工作流专属技能】段（与既有行为一致）

### Requirement: 无分类技能不消失与失效可见不回归
分类解析不出（目录无分类、未知分类值）的挂载技能 SHALL 照常注入（归入兜底全可见语义）；挂载技能失效（目录中已不存在）的标红提示 SHALL 保持全量可见，不因本变更的过滤逻辑被隐藏。既有的分类解析规则（目录即分类、文件头「> 分类：」可覆盖、未知分类原样保留）SHALL NOT 改变。

#### Scenario: 未分类技能照常注入
- **WHEN** 某挂载技能的分类无法解析为已知三类之一，且其任务工作流在映射表中
- **THEN** 该技能仍被注入（按未知分类兜底可见处理），不被过滤掉

#### Scenario: 失效技能标红不受影响
- **WHEN** 用户打开 Agent 配置的挂载选择器
- **THEN** 已挂载但目录中已不存在的技能仍标红显示「已失效」，行为与既有一致
