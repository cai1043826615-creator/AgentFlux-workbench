## Why

《工作台全功能核验报告_2026-09-17.md》对多 Agent 电商工作台做了全功能实操核验，结论：核心链路真实可跑（真实渠道跑通 #41 全链），但存在 **5 个 P1（3 个导致用户"卡住做不下去"）+ 15 个 P2 + 8 个 P3**，且知识库赋能链路因「任务创建后无法补挂资料」「小助理整理零入口」两个断点在实际使用中走不通。需求方已对全部缺陷逐条拍板处置决议（报告 §8.1，2026-09-17 确认），本 change 按决议落地修复。

## What Changes

**① 知识库赋能链路打通（§8.4 第 0~7 步，最高优先）**
- 任务详情页「关联知识库资料」面板补「＋ 添加 / 编辑」入口，复用 `KbRefPicker` + `api.putTaskKbRefs`（修 **D-19**）；后端补 `docPath` 缺失 400 校验
- 热点卡片主操作改为唯一按钮「**收进灵感库**」：小助理直接整理**落盘到 `知识库/灵感库/`**（不设草稿区、不做"工作台"页面，§8.3 定案）；移除卡片上的「挂到工作流」
- 总览带「小助理」右侧加三按钮：整理热点素材 / 整理文档 / 知识库体检（复用 `Btn`/`AgentCard`，对应后端已实现的 `POST /api/kb-assistant/organize` 三型）
- 总览带「灵感库」入口改指向真实 `知识库/灵感库/` 目录，计数改为目录实际文档数
- 「挂到工作流」迁至知识库文档行 + 任务详情页；两处只列可执行任务、回显「已挂到 #N」（修 **D-24**）
- 移除虚拟目录 `助理收件箱/`、清界面"收件箱 / 草稿区"字样、删 `dirDisplayName.ts` 死配置；健康度/孤岛、历史版本两处**界面隐藏、代码保留**（D-21/D-25 决议）
- 承诺文案精确化：「工作台只会在 `知识库/灵感库/` 这一处**新增**由小助理整理产出的文件；绝不修改、删除或移动你原有的任何文件」——同步知识库设置弹窗 + `AGENTS.md` 铁律 10 + 设置弹窗明示写入目录

**② 第一梯小改动高收益（P1 + 高频体验）**
- **D-01**：遗留阶段任务（xhs-image）静默卡死 → 阶段不存在时显式报错 + 启动校验；按决议删除 5 个老任务（#27/#20/#19/#18/#14）
- **D-02**：新建任务弹窗小视口下按钮不可达 → Modal 加 `maxHeight:90vh` + `overflowY:auto`
- **D-05**：「确认并开工」名不副实 → 文案与行为对齐
- **D-06**：无参考图仍发 400 → 前端守卫
- **D-07**：审批 Toast 永久驻留堆积 → 同 key 清理
- **D-09**：负责人显示不刷新 → 后端广播带 ownerName
- **D-10**：「类型」硬编码 → 按 workflowId 取
- **D-12**：界面暴露内部阶段 id（xhs-image）→ 历史阶段别名表（改后全局 grep 复查，U7）
- **D-22**：图片顺序不确定 → 按 groups 声明顺序重排
- **D-23**：文案摘要取错阶段 → 按阶段优先取正确交付物

**③ 第二梯结构性优化**
- **D-03/D-04**：生图结果**落地为文件**（`backend/data/uploads/` 复用既有 `/uploads/:file` 路由，content 只存相对路径）+ 列表接口复合索引 + `UPDATED_AT_EXPR` 改 LEFT JOIN + 搜索只读元信息（**BREAKING**：`deliverables.content` 存图片的形态从 base64 改为文件路径，接口响应体积骤降）
- **D-08**：知识库设置弹窗 Esc 失效 → 按 G3 抽取统一弹窗（先抽组件再使用）
- **D-14**：头像按钮补 aria-label
- **D-15**：弱对比度 `--color-ink-faint` → 令牌级校准（同步 `docs/规范/01_UI设计与组件规范_0916.md` token 表 + `check-ui-rules.mjs`）
- **D-16**：2 个 README 冒烟脚本已失败 → 修复脚本或文档
- **D-26**：关联资料展示实际命中路径 + 期望≠实际时轻提示
- **D-27/D-28**：筛选/搜索作用域说明扩展现有入口；知识库入口数量收敛
- **D-29~D-32**：知识库/星图页撑满视口不整体滚动（去 `overflow-auto` 改 flex+min-h-0）；星图画布去 `h-[62vh]` 改撑满剩余高度；左栏自身滚动 + 标签默认收起；左栏折叠态工作流与展开态**同源**渲染（`workflows.map`，删硬编码占位）；星图标签多选改弹窗（复用 `Modal`）

**④ 热点模块（§9 定案路线）**
- 热点定位改「**产出灵感雷达**」：回答"现在流行什么、能变成什么产出"
- 源层：**删除国家统计局** + **关闭 AI HOT** + 新增 4 个热榜源（百度热搜 / 60s·微博 / 60s·抖音 / 今日头条热榜，端点照 hot-trend-pivot tasks.md 1.1–1.4）；保留电商派/网经社；保留已定案新增的淘宝/天猫规则中心、小红书规则公告页；**A 档不接小红书内容源**
- **AI 批量打标**（新建 `backend/src/knowledge/hot-tagging.ts`）：单次 LLM 批量判断「产出方向 / 可参考 / 无关」，随缓存 TTL 复用，失败降级"可参考"（修 **D-33** 单源垄断——不再按来源顺序截断）
- 展示层三分组：HotView 从「必看/浏览/其他」改为「产出方向 / 可参考 / 无关」，「无关」默认折叠；统计口径同步
- 关注域配置降级为「源管理」（关键词编辑区隐藏、数据不删）；源作用域作泛热榜兜底闸门（**建议，待确认**）
- 工程：缓存按源打 key / 空响应防御 / 三层去重（0911 调研 §5.3，仍有效）

**⑤ 渠道自检（D-11）**：生图渠道自检结论修正（不再对设计师报错）

## Capabilities

### New Capabilities

- `hot-trend-radar`: 热点产出灵感雷达能力——泛热榜源接入、AI 批量打标三分组（产出方向/可参考/无关）、「收进灵感库」沉淀通道（直接落盘 `知识库/灵感库/`，不设草稿区）

### Modified Capabilities

- `daily-hot`: 面板定位从资讯播报改为产出灵感雷达；分组模型替换（必看/浏览/其他 → 产出方向/可参考/无关）；源结构变更（删统计局、关 AI HOT、加泛热榜源）；统计口径替换
- `kb-assistant`: 新增「收进灵感库」直接落盘职责（hot 型整理写 `知识库/灵感库/`）；总览带新增三个整理入口按钮；对 Vault 承诺从「只读」精确化为「只新增于灵感库目录」
- `content-delivery`: 审批 Toast 同 key 清理；图片顺序按声明顺序；文案摘要按阶段取；阶段名别名化（不暴露内部 id）
- `workflow-engine`: 阶段不在工作流定义时显式报错（不再静默卡死）；内置工作流启动校验
- `task-board`: 新建任务弹窗可滚动（小视口可用）；「确认并开工」文案与行为对齐；参考图守卫；「类型」按工作流派生；负责人实时刷新
- `knowledge-base`: 任务详情可补挂/修改关联资料；设置弹窗 Esc 可关（统一弹窗组件）；关联资料显示实际命中路径；健康度/孤岛界面隐藏（代码保留）；页面撑满视口不双滚动；标签默认收起；入口与命名收敛
- `knowledge-graph`: 星图画布高度自适应（去固定 62vh）；标签多选改弹窗
- `shell-layout`: 左栏折叠态工作流与展开态同源渲染（删硬编码占位）；头像按钮可访问名称
- `deliverable-provenance`: 生图落地为文件（content 存相对路径）；交付物搜索走元信息；版本历史界面隐藏（代码保留）
- `channel-health`: 生图渠道自检结论修正（设计师不再误报）
- `agent-observability`: 健康度口径三通道合并（任务引用 + Agent 挂载 + 文档互引）——按决议界面隐藏、接口保留
- `xhs-note-workflow`: 阶段显示名别名化（「封面配图/首图设计」统一，不暴露 xhs-image 内部 id）
- `hot-context`: 「挂到工作流」入口迁至知识库界面与任务详情页；`task_hot_refs` 通道去留**待确认**（T1，不擅自决定）
