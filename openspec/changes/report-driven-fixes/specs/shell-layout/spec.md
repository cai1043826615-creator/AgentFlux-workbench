## MODIFIED Requirements

### Requirement: Global top bar

- 头像按钮等图标控件 SHALL 具备**可访问名称**（`aria-label`，修 D-14）。
- 左栏**折叠态**的工作流分区 SHALL 与**展开态同源**渲染（`workflows.map()`，修 D-30）：折叠态不得只渲染"当前工作流"一项、不得硬编码「直播带货上架 / 跨境选品」假占位；真实工作流（电商新品上架、小红书种草笔记）折叠态均可切换；删除两个假占位项。

#### Scenario: 头像按钮有可访问名称

- **WHEN** 辅助技术读取头像按钮
- **THEN** 能获得有意义的名称（如"用户菜单"）

#### Scenario: 折叠态工作流与展开态一致

- **WHEN** 用户收起左栏
- **THEN** 折叠态工作流分区渲染与展开态相同的真实工作流列表（两个真实工作流均可切换），无假占位项
