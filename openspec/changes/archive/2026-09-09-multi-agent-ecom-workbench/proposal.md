## Why

电商团队的新品上架涉及文案、图片、校对多角色协作，目前靠人肉流转、聊天工具散落沟通，产出物缺乏统一预览与审批闭环。需要一个**多 Agent 协同推动工作流的工作台**：Agent 各司其职自动推进任务，人只在关键产出点拍板，把「资料 → 文案 → 主图 → 详情图 → 校对 → 归档」的电商新品上架全流程搬到一处可看、可审、可聊、可交付的 Web 工作台中。

## What Changes

- **新增 Web 工作台应用**（低保真线框已定稿：灰白线框风、三栏布局，见 `2026-09-08-电商新品上架工作流设计/低保真线框-可交互版-多Agent电商工作台.html`；**实际开发阶段的 UI 采用 Quiet Signal 设计语言**——近白画布、黑色信息层级、衬线 Display 标题、有限紫色信号色，已由用户指定替代初稿的明亮电商风），三栏布局：
  - 顶部全局栏：工作群 / 私聊 / 任务角标 / 在岗 GROUP / 主题切换
  - 左侧栏（可折叠）：工作流卡片列表 + 设置
  - 右侧栏（可折叠）：聊天窗口
- **工位（Workstation）**：管理不同 Agent 的岗位卡片——人设可编辑、可挂载 skill 与文件、按 Agent 隔离相关内容、可独立配置模型、显示在线状态。
- **任务看板**：主页 4 列「规划中 / 进行中 / 待确认 / 已完成」，任务沿工作流自动推进并更新位置；右上角「+ 新建任务」。
- **新建任务**：输出任务内容（产品资料、需求等）与用户**确认后** AI 才开工。
- **工作流**：电商新品上架 6 阶段（需求对齐 → 卖点文案 → 主图设计 → 详情图设计 → 主管校对 → 交付归档）；两个人工拍板点（卖点文案输出、主图输出），其余阶段自动流转；主管校对发现问题可回退对应阶段。
- **任务状态栏页**（替代看板视图）：任务简介、工作流阶段进度、待确认事项、任务流程预览、右侧属性面板、活动日志。
- **聊天**：可私聊各 Agent（点工位头像跳转私聊），另有群聊——完成节点、主管校对环节、人工审批等都在群内沟通。
- **内容交付**：任务状态栏页内「内容交付」标签页——**左右等宽并排两栏**（左「文案成品」｜右「图片成品」），**板块按交付状态驱动显示**：未产出/生成中显示占位（含脉冲指示），待拍板时显示内容与采纳/打回按钮，已确认后只显示状态标、**不再显示采纳/打回按钮**；图片逐张采纳/打回，全部处理完后联动任务状态机（有打回→返工、全采纳→自动推进下一阶段），在工作台内直接预览。
- **工作流图编排 + 并行执行**：6 阶段以「节点 + 边 + 条件分支」的图结构定义（借鉴 StateGraph 式编排）——拍板点、主管校对均为分支边；主图/详情图阶段内部多图并行生成，按渠道分组、组内串行防限流，每张图完成即时上报进度。
- **Agent 可观测性**：记录每次 Agent 执行的耗时、成功/失败与错误摘要（借鉴 AOP 注解思路），工位卡片与统计视图呈现执行次数、成功率、平均耗时。

## Capabilities

### New Capabilities

- `shell-layout`: 工作台整体三栏布局——顶部全局栏、可折叠左侧栏（工作流卡片 + 设置）、可折叠右侧聊天窗口
- `workstation`: 工位——Agent 岗位卡片、人设编辑、skill/文件挂载、按 Agent 内容隔离、独立模型配置、在线状态
- `task-board`: 任务看板——4 列（规划中/进行中/待确认/已完成）、新建任务（需确认后开工）、任务卡片与流转
- `workflow-engine`: 工作流引擎——电商新品上架 6 阶段图编排（节点/边/条件分支）、阶段流转、人工拍板点、主管校对与回退、阶段内并行执行
- `chat`: 聊天——私聊 Agent、群聊、节点完成/校对/审批事件推送
- `content-delivery`: 内容交付——左右等宽两栏（文案成品/图片成品）、板块按交付状态驱动显示（占位/待拍板/已确认）、逐张图片采纳/打回并联动状态机、工作台内预览
- `agent-observability`: Agent 可观测性——执行日志、耗时/成功率统计、工位卡片与统计视图展示

### Modified Capabilities

- 无（全新项目，不修改既有 spec）

## Impact

- **全新前端应用**：单页 Web 工作台（React + TypeScript 类现代栈，最终栈以设计实现阶段确定）
- **全新后端服务**：Agent 编排、工作流状态机、任务存储、聊天消息流（技术栈待设计阶段确认）
- **外部依赖**：多模型 LLM API（不同 Agent 可配置不同模型）、图片生成能力（设计师 Agent 输出）
- **新增观测数据**：Agent 执行日志与统计（SQLite 存储，摘要级、可定时清理）
- **并行控制**：阶段内多图并行生成按渠道分组、组内串行，规避 LLM/生图渠道限流
- **不影响既有功能**：本项目为独立新应用，与当前目录其他内容无耦合
