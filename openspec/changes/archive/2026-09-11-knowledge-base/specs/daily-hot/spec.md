## Purpose

提供每日热点面板：从公共匿名热点 API 拉取聚合热点，按可配置的电商化关注域过滤分层展示，支持缓存与降级，并可将单条热点人工转化为电商任务，让热点信息进入工作流。

## ADDED Requirements

### Requirement: 热点拉取与展示
系统 SHALL 从公共匿名热点 API 拉取聚合热点（含标题、摘要、来源、分类、链接），按分类展示在热点面板；拉取结果 SHALL 带缓存（如 15 分钟 TTL），避免重复请求。

#### Scenario: 成功拉取热点
- **WHEN** 热点 API 可用且用户打开热点面板
- **THEN** 面板展示分类热点列表，每条含标题、摘要、来源与链接，并标注数据时间

#### Scenario: API 不可用降级
- **WHEN** 热点 API 请求失败或超时
- **THEN** 面板展示缓存数据（若有）或明确错误提示，且不影响知识库其他功能与工作流板块

### Requirement: 电商化关注域过滤分层
系统 SHALL 按关注域配置对热点进行过滤与分层（如「必看 / 浏览 / 其他」）；默认关注域 SHALL 面向电商/品类/平台场景（如品类趋势、平台规则、竞品动态、促销节点），而非通用行业热点。

#### Scenario: 命中关注域进入必看
- **WHEN** 一条热点命中至少一个已启用关注域
- **THEN** 该热点进入「必看」层并置顶展示

#### Scenario: 未命中关注域
- **WHEN** 一条热点未命中任何已启用关注域
- **THEN** 该热点归入「其他」层，不置顶

### Requirement: 关注域配置
系统 SHALL 支持用户自定义关注域（关键词/规则），配置保存在本地（不入版本库），修改后重新拉取即生效。

#### Scenario: 自定义关注域
- **WHEN** 用户新增或修改关注域关键词并保存
- **THEN** 后续热点的过滤分层按新配置执行

### Requirement: 热点创建任务
系统 SHALL 支持从单条热点一键创建电商任务：点击热点卡片上的「创建任务」后，新建任务表单预填热点标题与摘要，由用户人工确认后进入工作流板块（板块 A）的任务创建流程。

#### Scenario: 从热点创建任务
- **WHEN** 用户在热点卡片点击「创建任务」
- **THEN** 新建任务弹窗打开并预填标题与描述（来自热点），用户可修改后按既有流程确认开工

#### Scenario: 不自动创建
- **WHEN** 用户仅浏览热点
- **THEN** 系统不自动生成任何任务或选题
