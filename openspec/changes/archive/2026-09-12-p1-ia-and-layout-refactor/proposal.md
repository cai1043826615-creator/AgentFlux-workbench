## Why

P0 修掉了 6 项功能缺陷后，第二轮走查中真正影响信息架构的问题仍在：知识库总览带塞了 5 类信息却只有 1 类对运营有决策价值；知识库与星图两页的侧栏各自为政、折叠控件位置各异；「重点目录」硬编码 2 个、改名要动配置文件；搜索无候选；文档引用一律跳页打断上下文；顶栏把「一次性授权」与「高频入口」并列。这些不是孤立的样式问题，而是同一批交互断口——本变更统一收口。

同时本变更承接 P0 归档时**主动领先于实现**的 `task-board` 列宽要求：P0 主 spec 已写入「四列等宽且随容器自适应」，但代码仍是固定 300px，本变更将其落地。

## What Changes

**布局与卡片**

- 看板四列改为**等宽自适应**（`flex-1` + `min-w-[240px]` 兜底）：左右栏折叠/展开、拖动分隔条、浏览器缩放时列宽随之重算，不再出现右侧空白或被侧栏遮挡；面板过窄时才横向滚动。
- 看板卡片**Agent 头像移到右上角**，释放一行高度；删除已完成卡片底部与 badge 重复的「● 已交付 · 已完成」状态行。
- 卡片副标题按走查 N12 **补足信息**（如「等待你处理 · 已等待 3 小时」），保留 badge 作为状态标识，两者职责分离。

**工位栏**

- 默认**展开**（原为默认折叠）。
- 折叠态改为**头像行**：每个 Agent 显示小头像 + 状态点 +【名字】+【岗位】，替代原先只有一行灰字紧凑条。

**审批条（走查意见 #16 / §0 判断 3）**

- 改造而非删除：把卡片内的「采纳 / 打回」按钮**提升到审批条内**，说明缩为一行（如 `待你确认 · 采纳后自动进入主图设计`），消除 55 字长句横铺的问题。

**通知归位（走查意见 #1 / N15）**

- 顶栏 `NotifyControl`（复选框 + 「开启通知」）整体移入**左栏「运行设置」弹窗**新增的「通知」分区。
- 顶栏只保留「任务」入口与连接状态点；任务角标从裸数字改为有含义的「7 待确认」。
- 权限被拒时在设置内给出可操作指引（当前点击无任何反馈）。

**知识库信息架构**

- 总览带从「4 技术计数卡 + 星图缩略 + 最近更新 + 使用率 + 孤岛」重构为**1 个核心指标 + 3 个可点入口**；「关联边 / 目录数」这类对运营无决策价值的统计移除。
- 「连接设置」改名**「知识库设置」**，星图页同样提供入口；弹窗内容分区为「接入 / 重点目录 / 索引」。
- 抽取公共 **`KnowledgeSidebar`** 组件（可折叠 + 目录树 + 标签），知识库页与星图页共用，顺带把「收起目录」控件**移入目录面板标题栏**（原在页面右上角，距目录约 1000px）。
- 知识库搜索支持**输入即出候选**（候选 = 文档标题 + 标签，非历史记录）。
- 阅读区空态改为**引导区**（最近阅读 + 今日热点入口 + 健康度摘要），不再只显示一行灰字。

**重点目录可维护（走查意见 #8）**

- 「重点目录」从硬编码 2 项（`10_raw/products` / `wiki/brand`）升级为**用户可增删改**的列表，知识库页与星图页共用同一份数据；需扩展 `packages/shared` 类型与后端读写路由。

**目录中文显示名映射（走查意见 #5，已定案）**

- 目录树显示「产品资料 / 品牌规范 / 灵感库」等中文名，**不改动 Vault 真实文件夹**；悬停或设置中可见真实路径。

**任务详情**

- 删除与主标题重复的 meta 行（任务编号已在面包屑中）。
- 正文内混入的机器字段（热点来源 / 原文 URL / 关注域）移入右侧属性面板「来源」区块，原文链接做成可点的「查看原文 ↗」。

**命名统一（走查意见 #9 / #10）**

- 「关注域与源配置」（按钮）与「关注域与数据源配置」（弹窗标题）统一为**「热点源配置」**。
- 「今日暂无多源共振事件 ?」改为一行灰字空态，不再占用胶囊位，问号的可点帮助改为内联说明。

**非目标**：不含 P2 的 DocPreviewModal、灵感库重构、知识库小助理功能实现（总览带仅为小助理**预留入口位**，复用 `ui.tsx` / 工位语义的既有组件，P2 可直接挂载）；不改动 Vault 内任何文件；不改动工作流状态机与 WS 协议。

## Capabilities

### New Capabilities

无。本变更为既有能力的需求调整，不引入新能力。

### Modified Capabilities

- `task-board`: 四列列宽由「固定宽度 + 横向滚动」改为「等宽自适应 + 最小宽度兜底」；卡片补 Avatar 右上角布局要求；卡片副标题与状态标识职责分离。
- `workstation`: 工位栏默认展开态，并规定折叠态的信息构成（头像 + 名字 + 岗位）。
- `content-delivery`: 审批条由「仅说明」改为「承载采纳/打回操作 + 单行说明」。
- `shell-layout`: 通知授权控件从顶栏移入运行设置；顶栏元素收敛；任务角标语义化。
- `knowledge-overview`: 总览带信息构成由 5 类改为「1 核心指标 + 3 入口」，并为小助理预留入口位。
- `knowledge-base`: 「连接设置」更名并可分区；知识库搜索新增候选；阅读区空态改为引导区；新增目录中文显示名映射；抽取公共侧栏。
- `knowledge-graph`: 提供「知识库设置」入口；采用公共侧栏；「重点目录」改为可增删改并与知识库页共用。
- `task-explorer`: 移除重复 meta 行；机器字段移入属性面板来源区块。
- `daily-hot`: 「关注域与源配置」统一命名为「热点源配置」；今日必看空态改为一行灰字。

| 层 | 改动 |
