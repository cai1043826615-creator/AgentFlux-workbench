# 电商视觉规范

> 描述：电商主图与详情图的视觉规范：首图要素、构图与配色要求、卖点排版与系列图一致性，供设计师 Agent 挂载后约束生图与审图。
> 分类：电商

## 一、首图（主图）五要素

1. **钩子文案**：3–8 字大字标题，说清「这是什么 + 核心利益」（如「10 秒出汁 免清洗」）。
2. **主体清晰**：产品占画面 ≥ 50%，无杂物遮挡，一眼看懂卖的是什么。
3. **高对比**：文字与背景强对比；白底图用深色字，场景图压暗角后再压字。
4. **焦点唯一**：一个画面只讲一个卖点，禁止多卖点堆砌。
5. **品牌一致**：配色、字体风格与品牌调性统一（见《品牌视觉规范》）。

## 二、构图与规格

- 主图：白底图（平台审核要求）+ 场景图组两种都出；方形 1:1，主体居中略上。
- 详情图：按「痛点场景 → 产品登场 → 卖点分述 → 规格参数 → 售后保障」顺序组图，每张只承载 1–2 个信息点。
- 文字量：首图 ≤ 2 行；详情图单屏 ≤ 40 字，超出拆页。

## 三、卖点排版

- 数字具体化：「10 秒出汁」优于「快速出汁」。
- 图文一致：图里出现的每个卖点必须能在文案包（标题/5 条核心卖点）中找到出处，反之文案承诺的卖点图必须体现——不一致即质检打回项。
- 禁止大字报式堆字、禁止描边发光特效叠满、禁止拉伸变形的产品图。

## 四、平台差异注意

- 电商详情页信息可密集；小红书配图必须是真人生活场景/自然光随拍质感，**不得使用电商主图、白底图、大字报排版**（由 xhs 工作流 prompt 约束，设计师自查）。
