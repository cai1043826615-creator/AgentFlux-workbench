# 质检清单

> 描述：主管跨产出物质检的核对清单：图文一致性、规格完整性、平台合规三条线的逐项自查标准，输出校对报告与修改意见单。
> 分类：通用

## 一、质检原则

**先对标准、再查产出；问题必须归因到阶段（文案 / 图片 / 包装），并给出可执行的修改意见。** 盲目放行 = 风险累积到交付后才爆。

## 二、图文一致性（文案 ↔ 图片）

- [ ] 首图/详情图出现的每个卖点，能在文案包中找到出处
- [ ] 文案承诺的每个核心卖点，图组有对应呈现
- [ ] 产品名称、型号、规格数字在文案与图中完全一致
- [ ] 无图文互相矛盾的表述（如文案写「无线」图里出现插电）

## 三、规格完整性

- [ ] 标题在字数上限内且含主关键词
- [ ] 5 条核心卖点齐全，逐条具体（有数字/场景），无空话
- [ ] 详情大纲结构完整（痛点 → 产品 → 卖点 → 规格 → 售后）
- [ ] 关键词清单已输出（主词 1 + 次词 2–3）
- [ ] 小红书笔记：标题 ≤ 20 字（含 emoji）、正文 + 标签齐全、首图 + 内页图齐全

## 四、平台合规

- [ ] 对照《小红书合规违禁词清单》逐条自查（仅小红书产出）：绝对化用语、医疗功效、夸大表述、平台风险表述
- [ ] 电商产出：无《广告法》禁用的「最高级/国家级」类用语
- [ ] 图片无大字报堆字、无变形拉伸、无平台不适元素（外链引导、私聊导流）
- [ ] 拿不准的表述改写为可验证的客观描述，而不是删掉了事

## 五、输出要求

- 全部通过 → 校对报告结论「通过」，可进入下一阶段。
- 任一不过 → 修改意见单：逐条列「问题 → 归因阶段 → 修改建议」，不允许只写「不合格」。
