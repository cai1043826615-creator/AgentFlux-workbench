| 3 | 工作群头像未显示 + 优化未落地 | 排查结论：①群头像 /groups/ecom.png 代码与文件均正常，用户侧为旧 bundle 缓存（重启 vite 干净编译解决）；②事件折叠行 + 筛选按钮原在消息列表内部顶部，聊天区默认滚动到底部（最新消息）→ 顶部被滚出视口，用户看不到 = 「未落地」观感。修复：ChatPanel 将筛选按钮组 + 「n 条系统事件 ▾」折叠行移到聊天区固定区（ChatHeader 下方常驻，border-b 分隔），不随消息滚动；展开后 evt 原位显示；「消息/事件」筛选本地过滤不变 | 实测：固定区滚动到任意位置仍可见（172px 不变）；展开显示 158 条 evt；消息筛选隐藏折叠行；事件筛选只显示 evt；群头像 ecom.png 40px 正常 |
| 4（附修） | 返工完成后拍板 Toast 不弹（排查 #3 时发现的真 bug） | 根因：decide（打回 reject）的 HTTP 请求同步等待后端返工（生图 ~40s）完成才返回，返回后前端把返工完成时**刚广播的新 approval:prompt 条目**从 approvalQueue 一并移除（与 WS 推送同批）→ Toast 没机会弹。WS 探针铁证：approval:prompt 广播正常到达，前端逻辑正常，问题在 decide 响应回调误清。修复：useWorkbench.decide 改为 **reject 乐观移除**（请求发起时清旧条目；返工完成的新条目保留触发 Toast）；approve 保持响应后移除 | 实测：打回 #6 → 返工完成 → Toast「待你拍板 #6 主图设计」正常弹出（500px）；WS 探针收到 approval:prompt:6 |
