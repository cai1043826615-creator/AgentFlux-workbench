8图片生成长时间卡住，疑似后台异常已由AI实测（根因明确）需你换渠道

根因（已实测定位）：hasImageChannel() 返回 true（你的 .env.local 配了 IMAGE_BASE_URL/KEY），但该端点不可达 → 真实网络请求挂到超时才失败。三张图串行 + 内层重试，按 180s 算最坏要 9~27 分钟。
本次修复（三层）：
① 单图超时 180s → 30s（最坏 90s 出结果，不再"假死"）；
② 生图失败时把原因写入卡片副标题（生成失败：xxx｜可重试），不再静默停在进行中；
③ 前端「确认开工」加 pending 态 + 失败 toast（原来 void 吞掉异常，错误完全不可见）。
仍需你处理：换一个可用的生图渠道，否则只会更快地看到失败提示（而不是卡住）。
