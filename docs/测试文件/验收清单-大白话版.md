# 工作台验收清单（大白话版）

> 怎么看这个页面：打开浏览器访问 `http://127.0.0.1:4310`。
> 页面从上到下、从左到右大概是：最上面一条顶栏 → 左边菜单 → 中间主区域（顶部一格一格的是「工位」，下面一大片是任务看板）→ 右边聊天窗口。
> 下面的每一项都写着「你做什么」和「正常应该看到什么」，对照打勾即可。

---

## 第一部分：界面检查（页面长什么样，对不对）

### 1. 最上面那条顶栏
- [ ] □ 你做什么：看页面最顶部一行。
  正常应看到：左边有个黑色小方块写着「电」，旁边是「电商工作台」；右边有「任务」「在岗 3 · 忙碌 0」「实时连接」。
- [ ] □ 你做什么：看「任务」两个字。
  正常应看到：有任务在等你确认时，它右上角会出现一个**紫色小数字**（有几个就显示几）；没有待确认任务时没有数字。

### 2. 左边菜单
- [ ] □ 你做什么：看左边一列。
  正常应看到：上面写着「工作流」，下面一行黑底白字「电商新品上架」（右侧有个数字是任务总数），再下面一行小字「6阶段 · 2确认点」；再往下是灰字的「直播带货上架」「跨境选品」（占位，点了没反应是正常的）；再往下「通用」区有「执行观测」「设置」。

### 3. 中间顶部的「工位」（三个工作格）
- [ ] □ 你做什么：看中间最上面。
  正常应看到：一行小字「工位 WORKSTATIONS」，右侧「＋ 添加 Agent」；下面并排三格：
  第一格「文案 · 美美 / 模型 deepseek-chat」、第二格「设计师 · 平平 / 模型 gpt-image-2」、第三格「主管 · 波波 / 模型 deepseek-chat」。
  每个格子名字前有一个小圆点：**待命=灰色、在线=绿色、忙碌=紫色并一闪一闪**；格子右侧有「设置」小按钮。

### 4. 中间看板（四块区域）
- [ ] □ 你做什么：看工位下面的大区域。
  正常应看到：最上面一行「任务看板」大标题，旁边小字「电商新品上架 · 6阶段 · 2确认点 · N个任务」，右上角「＋ 新建任务」按钮；下面**并排四列**：规划中 / 进行中 / 待确认 / 已完成，每列顶部有小字计数。

### 5. 任务卡片长什么样
- [ ] □ 你做什么：看任意一张任务卡。
  正常应看到：左上角「#数字」编号 + 任务名（衬线字体）；下面一行灰色小字说明当前状态（比如「主图设计完成 · 待你确认」）；再下面一个彩色小标签（待确认=橙色「待你确认 · 主图设计」、已完成=绿色「✓ 已完成」）；再下面一条 6 小段进度条（走到的段是紫色，走完的段是绿色）；再下面负责人小头像和名字；最下面一排按钮。
- [ ] □ 你做什么：看四种状态下的按钮。
  正常应看到：
  - 规划中 →「确认开工」按钮
  - 进行中 → 紫色闪点 + 「xx 推进中」小字（没有按钮）
  - 待确认 →「采纳」「打回」两个按钮
  - 已完成 → 「已交付 · 已完成」小字（没有按钮）

### 6. 右边聊天窗口
- [ ] □ 你做什么：看最右边一列。
  正常应看到：上面一排小按钮「工作群 / @美美 / @平平 / @波波」；中间消息区（系统事件是居中的灰色小字，如「── 进入阶段 · 卖点文案 ──」）；最下面输入框 +「发送」按钮。

## 第二部分：操作流程（从头到尾走一遍）

### 第 1 步：新建任务
- [ ] □ 你做什么：点右上角「＋ 新建任务」。
  正常应看到：弹出小窗，第 1 步让你填「任务标题」「产品资料」「目标平台」，下面有「下一步：确认内容」按钮，还有一行小字「确认后 AI 才开工」。
- [ ] □ 你做什么：随便填个标题（如「桌面小风扇」），点「下一步：确认内容」。
  正常应看到：第 2 步把你刚填的内容列成摘要，有两个按钮「返回修改」「确认并开工」。
- [ ] □ 你做什么：点「确认并开工」。
  正常应看到：小窗关闭，新任务出现在**规划中**列（灰色标签「需求对齐」+「确认开工」按钮）。注意：此刻 AI 还不会干活。

### 第 2 步：确认开工，等文案
- [ ] □ 你做什么：点任务卡上的「确认开工」。
  正常应看到：卡片挪到**进行中**列；右侧聊天里出现系统事件小字（进入阶段之类的播报）；Agent 开始干活时，顶栏「忙碌」数字会变成 1，工位里美美的小圆点变紫一闪一闪。

### 第 3 步：第一次等你确认（文案拍板）
- [ ] □ 你做什么：等一两分钟（文案阶段）。
  正常应看到：任务卡挪到**待确认**列，标签变橙「待你确认 · 卖点文案」；顶栏「任务」角标出现紫色数字 1；卡片下方出现「采纳」「打回」按钮。
- [ ] □ 你做什么：点这张卡，打开任务详情页。
  正常应看到：上方一排 6 个阶段小方块（需求对齐 › 卖点文案 › 主图设计 › 详情图设计 › 主管校对 › 交付完成），当前阶段是黑底白字；下面一块**紫色底**的提示条写着「待你确认 · 卖点文案 #编号」，还有「去内容交付页审批」按钮；右侧一列「属性」面板写着类型/当前阶段/进度/负责人等。
- [ ] □ 你做什么：点「去内容交付页审批」。
  正常应看到：切到「内容交付」页面，左边是「卖点文案」卡（有标题、5 条卖点、大纲、关键词标签），右边是「图片交付」卡（此时应该是「图片尚未产出」的提示）；页面底部有紫色审批条：「审批 · 待你确认 卖点文案 #编号」+ 意见输入框 +「打回并发送意见」「采纳并推进下一阶段」两个按钮。

### 第 4 步：试着打回一次（看返工）
- [ ] □ 你做什么：在审批条的意见框里写「文案再口语一点」，点「打回并发送意见」。
  正常应看到：任务卡回到**进行中**；聊天里出现打回事件（「── 被打回：文案再口语一点 ──」）；美美的圆点变紫忙碌，重新写文案；等它写完，任务再次回到**待确认**。
- [ ] □ 你做什么：这次点「采纳并推进下一阶段」。
  正常应看到：任务进入**进行中**（主图设计阶段），顶栏角标消失；聊天里出现「你已采纳」事件；卡片状态说明变成主图相关。

### 第 5 步：主图逐张确认
- [ ] □ 你做什么：等主图生成（要一两分钟，出真实图片）。
  正常应看到：任务回到**待确认**；打开「内容交付」，右边「图片交付」卡里出现「主图 / 详情图」两个小页签，主图下有 3 张缩略图，每张下面有「采纳」「打回」小按钮。
- [ ] □ 你做什么：点其中一张的「采纳」，再看另外两张。
  正常应看到：采纳的那张变成绿色「已采纳」且按钮消失；另外两张还有按钮。
- [ ] □ 你做什么：把剩下的图全部「采纳」。
  正常应看到：全部变「已采纳」后，任务自动推进到**详情图设计**（进行中，无按钮）；再等一会儿详情图 4 张自动生成完，自动进入「主管校对」。

### 第 6 步：主管校对与终审
- [ ] □ 你做什么：等主管（波波）校对完成。
  正常应看到：任务进入**待确认**；内容交付页面底部出现「主管校对 · 终审」区，左边是校对报告文字，右边是「放行 → 交付完成」按钮和「回退」选择框。
- [ ] □ 你做什么：点「放行 → 交付完成」。
  正常应看到：任务挪到**已完成**列，卡片标签变绿「✓ 已完成」，状态说明「已交付 · 已完成」，6 段进度条全绿；顶栏忙碌归 0。

### 第 7 步：聊天功能
- [ ] □ 你做什么：在右边聊天输入框打字，按回车或点「发送」。
  正常应看到：你的消息出现在右侧（黑底白字）；群聊里会有 Agent 回复（灰底）。
- [ ] □ 你做什么：点「@美美」再发一条。
  正常应看到：这条消息只在和美美的私聊里；切回「工作群」看不到它。

### 第 8 步：看统计
- [ ] □ 你做什么：点左边菜单的「执行观测」。
  正常应看到：三个工位卡片，每张显示执行次数/成功率/平均耗时；旁边「执行统计」卡有总执行/成功率/平均耗时大数字和每个 Agent 的成功率条；下面「执行日志」表格，每次 Agent 干活一条记录，有成功/失败标签。
- [ ] □ 你做什么：点工位卡上的「编辑」。
  正常应看到：卡片原地展开几个输入框（人设/模型/技能），改完点「保存」，卡片内容更新。

### 第 9 步：折叠与自动模式开关
- [ ] □ 你做什么：点左边菜单最下方「◀ 折叠左栏」。
  正常应看到：左边菜单收成一条窄条，中间区域变宽；点窄条上的「▶」恢复。
- [ ] □ 你做什么：点右边聊天底部「▶ 折叠聊天栏」。
  正常应看到：聊天收起，中间变宽；点「◀」恢复。
- [ ] □ 你做什么：点左边菜单「设置」。
  正常应看到：弹出设置小窗，说明「自动模式」：一种是**等你确认**（每个环节停下来等你点头，默认），一种是**全自动**（所有环节自动通过跑完）。选一种点「保存」。

## 第三部分：几个「看着对」的整体观感

- [ ] □ 页面没有花花绿绿的彩色小图标（笑脸、齿轮、购物车那种），全部是文字和点线
- [ ] □ 整体是白底、黑字、灰字，紫色只出现在：正在等你确认的提示条、激活的小页签下划线、忙碌闪点、按钮悬停时
- [ ] □ 页面不会横向超出屏幕（没有左右拖动条）
- [ ] □ 卡片、面板都是方角（不是到处圆滚滚的），只有按钮和输入框是轻微圆角

## 常见疑问

- **等了好久任务不动？** 先看顶栏「任务」角标——有紫色数字说明在等你确认，去内容交付页面处理即可。
- **想演示但不想花额度？** 在设置里把渠道密钥清掉，系统会自动用内置模拟内容跑完整流程（效果一样，只是文案/图片是模拟的）。
- **点「打回」没反应？** 打回需要先在意见框写一句话（或者系统会默认填「请按修改意见调整」）。
