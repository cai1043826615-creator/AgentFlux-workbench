## 一、涵涵上线（4 处出现 + 1 处不出现）

### 1.1 工位栏——涵涵**不在**里面 [已由我实测]

- 在哪：首页（任务看板）顶部「工位 WORKSTATIONS · 3 个」
- 看什么：恰好 **3 张卡——美美（文案）、平平（设计师）、波波（主管）**
- 过的标准：**没有第四张「涵涵」卡**。这是你定案「工作流不体现小助理」的核心验证点

### 1.2 工位栏收起/展开仍正常 [需你亲测]

- 在哪：工位栏右上角「收起 ▴」
- 操作：点「收起 ▴」→ 应变成一行「工位 ▸美美·文案 ▸平平·设计 ▸波波·主管 展开 ▾」
- 过的标准：折叠行里每个 Agent 显示**小头像 + 名字 + 岗位**；点「展开 ▾」恢复三张卡

### 1.3 Agent 状态页——涵涵出现 [已由我实测]

- 在哪：左栏「通用 → Agent 状态」
- 看什么：**4 张状态卡**，其中一张是「涵涵 · 助理」
- 过的标准：涵涵卡有头像、角色徽章「助理」、状态「待命」、执行统计
- 附加：涵涵的统计数字（运行次数等）应与美美/平平/波波**各自独立**，不混算

### 1.4 聊天面板——可与涵涵私聊 [需你亲测]

- 在哪：右侧聊天栏（若折叠，点右缘「展开」）
- 操作：私聊对象一排小头像里找到涵涵 → 点它
- 过的标准：出现与涵涵的私聊会话；发一条消息（如「你好」），涵涵会回（真实 LLM 或降级模板都算过）
- 附加确认：群聊「电商工作群」里，涵涵**不出现**在群播报署名中

### 1.5 涵涵的设置弹窗 [需你亲测]

- 在哪：Agent 状态页涵涵卡上的「配置」按钮，或下面 2.3 的总览带涵涵卡「配置」
- 过的标准：弹出与其他 Agent **同款**设置弹窗，可编辑人设/模型并可保存

## 二、知识库页总览带（位置 + 收起）

### 2.1 涵涵位在**最右侧** [已由我实测]

- 在哪：左栏「知识库」→ 页面顶部总览带
- 看什么：总览带从左到右依次是 **[待在用的资料] [灵感库] [全部文档] …… [涵涵]**——涵涵在**最右端**，不在中间
- 过的标准：涵涵卡是总览带最后一个元素

### 2.2 涵涵卡是真实 Agent 卡 [已由我实测]

- 看什么：卡上显示「涵涵」+「助理」徽章 + 状态点（待命=灰/绿）+「配置」按钮
- 过的标准：**不再是**之前那个「整理知识库与灵感 · 开发中」的灰色占位卡

### 2.3 收起 / 展开 [已由我实测 + 需你亲测手感]

- 操作：点涵涵卡右上角的「收起 ▴」
- 过的标准：收起后变**紧凑一行**（小头像 + 涵涵 + 展开 ▾）；再点恢复完整卡片
- [需你亲测] 收起/展开的尺寸手感是否舒服

### 2.4 涵涵「配置」能打开弹窗 [已由我实测]

- 操作：点涵涵卡上的「配置」
- 过的标准：打开 Agent 设置弹窗（与 1.5 同款）

## 三、草稿区（涵涵的三能力产出）

> 草稿区目前**暂无界面入口**（本轮后端能力先行），用验证步骤走 API 层。
> 你也可以跳过此项——三项产出已在后台各生成一份实测草稿。

### 3.1 草稿数据已存在 [已由我实测]

- 操作：浏览器地址栏输入 `http://127.0.0.1:4311/api/kb-drafts` 回车

- 若想看内容：`http://127.0.0.1:4311/api/kb-drafts/1`（1/2/3 逐个看）

### 3.2 草稿内容质量抽检 [建议你亲测]

- 打开草稿 1（文档整理），肉眼判断：

  - 参数/事实与原文一致（10000mAh、198g、GB 31241 等），**没有编造** ✓
- 过的标准：内容可信、结构清晰

### 3.3 只读承诺（本轮最重的红线）[已由我实测 + 建议你复核]

- 事实：涵涵执行了 3 次整理，前后对比 Vault 内 6 个 .md 文件的 SHA256 **逐一相同**，目录结构零变化
- 你的复核方式：打开 `docs/示例Vault/` 肉眼确认没有新增/丢失文件
- 过的标准：Vault 完全没被动过

## 四、文档预览弹窗（3 个入口 + 弹窗内导航 + 3 种关闭）

### 4.1 入口①：星图节点「阅读原文」[已由我实测]

- 在哪：左栏「知识星图」→ 点任意文档节点 → 右侧节点详情 → 点「路径 · 阅读原文」
- 过的标准：
  - **弹出预览弹窗**（页面不变暗跳走，星图还在背后）
  - 浏览器地址栏 hash **仍是** `#/knowledge-graph`（这是本功能的核心价值：不跳页）
  - 弹窗显示文档全文 + 右栏「目录内位置 / 标签 / 引用此资料的任务」

### 4.2 入口②：任务详情关联资料 [已由我实测]

- 在哪：首页点卡片「#12 溯源命中验证」→ 切「任务详情」tab → 右侧「关联知识库资料」→ 点「阅读原文」
- 过的标准：弹窗就地打开「磁吸充电宝产品资料」全文；**你没有离开任务详情页**
- 附加：这条用的是旧英文路径自动解析，能打开说明兼容修复生效

### 4.3 入口③：正文内链接 + 弹窗内切换 [已由我实测]

- 操作：在 4.1 打开的弹窗里，点正文中带下划线的关联文档（如「文案语气指南」）
- 过的标准：**同一个弹窗内**切换到新文档（弹窗不关、不跳页）；弹窗标题变成新文档名
- 再点头部「← 返回上一份」→ 回到上一个文档；栈空时该按钮置灰

### 4.4 「引用此资料的任务」区块 [已由我实测]

- 有引用的文档（如磁吸充电宝）：右栏列出「任务 #12」等，可点击
- 无引用的文档（如双11大促节奏）：右栏显示「暂无任务引用此资料」的灰字提示，**不是空白**

### 4.5 三种关闭方式 [已由我实测 + 需你亲测]

- Esc 键 → 关闭 ✓
- 点弹窗外深色遮罩 → 关闭 ✓
- 点右上角「✕」→ 关闭 ✓
- 关闭后你都在**触发前的原页面**（星图还在星图、任务详情还在任务详情）

### 4.6 「在知识库中打开 ↗」[需你亲测]

- 操作：弹窗头部点「在知识库中打开 ↗」
- 过的标准：跳到知识库页并在阅读区打开该文档（这是唯一允许的跳转，属于「深度阅读」出口）

### 4.7 知识库页内**不走弹窗** [已由我实测]

- 操作：在知识库页的文档列表里点一篇文档
- 过的标准：文档在**右侧阅读区原地打开**（不弹窗）——快速预览与深度阅读的分工保持
