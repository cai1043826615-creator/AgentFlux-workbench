# 技能挂载与工作流隔离优化建议（验收 #2/#3/#6）

> 来源：2026-09-14 验收单「技能分区挂载 · 技能库实体化」第 2/3/6 项用户备注。
> 交接对象：下一个实施 agent。以下文件路径、函数名均经源码核实，可直接开工。
> 前置事实：技能目录已迁至 `docs/示例Vault/技能库/{电商,小红书,通用}/`（backend/src/agents/skills.ts 的 `resolveSkillsDir()`），分类由所在中文目录名直接给出。

## 建议一：工作流级技能可见性与使用隔离（验收 #2/#3）

### 需求原话
「我想要是在不同工作流显示挂载的 skill，而不是所有的 skill 都显示。比如电商只显示并使用挂载的电商 skill 和我选择的 skill，小红书不会显示电商页的 skill 也不会使用。只有在 agent 配置才能看到左右分区挂载 skill 相关内容。」

### 现状（已核实）
1. **展示层**：`frontend/src/features/workstation/AgentSettingsModal.tsx` 的挂载面板按分类分区展示全部目录技能（电商→小红书→通用 + 已挂 N/M 计数 + 失效标红）；任务卡片/工作流页没有技能维度展示，也无过滤概念。
2. **注入层**：`backend/src/agents/smart-producer.ts` 已有 `WORKFLOW_SKILLS`（`小红书合规违禁词清单 → ['xhs-note']`）——工作流专属技能的**追加注入**，但**没有反向过滤**：电商任务若挂了小红书技能，全文照样进 prompt。
3. **数据层**：`agents.skills` 存展示名数组；技能目录自带 `category`（电商/小红书/通用）。

### 建议方案
1. **单一映射表（数据层）**：在 `packages/shared/src/`（或 smart-producer.ts 顶部）新增 `WORKFLOW_CATEGORIES: Record<workflowId, category[]>`，例如：
   - 电商工作流 → `['电商', '通用']`
   - 小红书工作流 → `['小红书', '通用']`
   - 未列出的 workflowId → 全分类可见（兜底，防新工作流技能凭空消失）
   替代散落的 `WORKFLOW_SKILLS` 字符串硬编码；工作流专属技能（合规清单）作为「强制追加项」独立保留，不受过滤影响。
2. **注入过滤（后端）**：`buildProducerSystemPrompt` / `smart-producer.ts` 组装技能段时，按任务 `workflowId` 查映射表过滤挂载技能（`skillMounted` 判定通过后再比对技能 `category`）。注意：注入过滤必须发生在读取全文之前，省 token。
3. **展示过滤（前端）**：任务详情/看板卡片如展示「所用技能」，按同一映射过滤；**只有 `AgentSettingsModal`（Agent 配置弹窗）保留完整三分区视图**——这是用户明确的边界：「只有在 agent 配置才能看到分区」。
4. **语义决策点（实施前与用户确认，二选一或按用户口径）**：
   - 「通用」技能是否对所有工作流可用？建议：是（兜底区语义，见 openspec design D2）。
   - 用户原话「电商只显示并使用挂载的电商 skill **和我选择的 skill**」——若指「某技能虽属小红书但用户显式挂给该 Agent 就要生效」，则过滤规则 = `category ∈ 映射表 OR 用户显式挂载标记`，需要给挂载关系加「显式跨域」标记（建议：不加标记，严格按分类过滤，语义更可预期；交用户拍板）。
5. **回归底线**：无分类技能不得消失（原 design D2）；失效标红仍全量可见；`WORKFLOW_SKILLS` 现有行为（合规清单进 xhs-note）不回归——`backend/src/agents/__tests__/skills.test.ts` 与验收脚本 C1 可复用。

### 涉及文件
- `packages/shared/src/`（映射表 + 类型）
- `backend/src/agents/smart-producer.ts`（注入过滤）
- `backend/src/agents/skills.ts`（如需按 category 快筛，`listSkills()` 已返回 category）
- `frontend/src/features/workstation/AgentSettingsModal.tsx` 及任务详情组件（展示过滤）

## 建议二：挂载选择改二级弹窗 + 滚动修复（验收 #6）

### 需求原话
「可用，但是挂载多了超出屏幕外面也不能下拉，另外我希望通过弹窗来选择。」

### 现状（已核实）
挂载面板内嵌在 `AgentSettingsModal.tsx` 配置弹窗内部；技能区最大高度有限，分区多了以后列表溢出且不可滚动（弹窗内滚动被外层吞掉）。

### 建议方案
1. **拆组件**：从 `AgentSettingsModal.tsx` 抽出 `SkillMountPicker`（新文件，建议放 `frontend/src/features/workstation/`）。
2. **交互**：点击「＋ 挂载 skill 和文件」打开**二级 Modal（或右侧 Drawer）**：
   - 左右两栏：左=已挂载（含分类徽标、失效标红、× 移除），右=可挂目录（按 电商/小红书/通用 分区 + 顶部搜索框按名称/描述过滤）；
   - 高度：`max-height: 70vh; overflow-y: auto`，分区标题 `position: sticky` 置顶；
   - 勾选即暂存于组件 state，底部「完成」按钮一次性 `PUT /api/agents/:id`（减少请求次数，也避免半保存状态）；
   - Esc/遮罩关闭，focus trap（用原生 `<dialog>` 或现有 Modal 基础组件）。
3. **顺手项**：二级弹窗打开期间外层配置弹窗禁止滚动（防滚动穿透）。

### 涉及文件
- `frontend/src/features/workstation/AgentSettingsModal.tsx`（入口改造 + 拆分）
- 新增 `SkillMountPicker.tsx`

### 验收要点
- 挂载 20+ 技能时二级弹窗内可完整滚动、分区标题吸顶；
- 搜索「SEO」能筛出目标技能；
- 完成前关闭弹窗不产生脏数据；失效项在左栏可见且可移除；
- 既有行为不回归：勾选持久化、分类徽标、失效标红（原验收单 #3/#4/#5 可直接复验）。
