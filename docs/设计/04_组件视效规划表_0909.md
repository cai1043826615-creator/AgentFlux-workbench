# 电商多 Agent 工作台 · UI 组件视效规划表（待确认版）

> 版本：v0.9（调研补齐中）｜ 日期：2026-09-08 ｜ 状态：**待用户确认**
> 目标：为「组件沉淀清单」（见 `docs/规范/01_UI设计与组件规范_0908.md` §4）中每个组件选定**视效参考来源**，落地「Aceternity 适度借鉴、克制型企业工作台」方向。
> 风格红线：近白表面 + 黑灰主色 + 稀疏紫色焦点 + 大结构直角 + 小控件 4px 圆角 + 默认无阴影；**不做**玻璃拟态 / 渐变光晕 / 粒子堆砌 / 层层圆角。
> 参考源：Aceternity UI（ui.aceternity.com）· 21st.dev · recent.design（页面级灵感）· godui.design。

> GodUI 明确禁用项（整类排除）：全部 3D 按钮变体、Tilt/Holographic/Liquid Glass 卡片、全部 Backgrounds（光晕/渐变/粒子）、Text 特效、Border Beam/Confetti/Spotlight、Dynamic Island、Dock、Swipe Deck、Split-Flap、Cover Flow、光标特效。
> GodUI 缺失项（转 shadcn/ui 或自建）：表格 Table、普通状态徽章、空态、文本域 Textarea。
> 动效规范采纳：GodUI [Motion Principles](https://godui.design/docs/motion/principles) 的 Restraint 原则（subtle beats flashy、只动画 transform/opacity/filter、prefers-reduced-motion）与 QS SPEC §4.6 一致，作为本项目动效实现依据。
> Aceternity 明确禁用项（整类排除）：全部光晕/渐变/玻璃/胶囊/3D/滚动炫技组件（Sparkles/Aurora/Background Beams/Spotlight/Glowing/Moving Border/Magnetic/Gooey/Vanish 胶囊外观/Animated Modal 展开动画等），详见 `aceternity-ui-调研报告.md`。
> Aceternity 缺位项（自建或 shadcn）：Toast、Table、Dropdown、Popover、Skeleton、Progress/Stepper、标准 Badge、标准 Input/Button——其基础组件页全部 404，本项目维持 Quiet Signal 既有实现。

## 2. 全局视效方向（页面级，来自设计决策 D6.1）

- **基调**：Quiet Signal 为主——近白画布、黑色信息层级、衬线 Display 标题、有限紫色信号色、无阴影默认。
- **gpt-taste 品味注入**：宽容器大标题（H1 ≤3 行）、章节级大间距（py-32 md:py-48 的呼吸感，工作台内适度缩放）、克制的滚动/悬停动效（滚动淡入、卡片 hover 微缩放）。
- **Aceternity 适度借鉴**：卡片 hover 微交互、焦点光晕（细 ring）、分割线装饰；**不做**玻璃拟态/强渐变/粒子。
- **全局效果图**：见 `预览图/UI视效果更新预览图/` 目录（规划图已输出，确认后实施）。
