## A. 全局壳层（对齐线框 .topbar / .left / .right / .ws-bar）

- [ ] A1 顶栏常驻：logo「电」+ 标题「电商工作台」+ 右侧「任务」按钮/「在岗 n · 忙碌 n」/「实时连接」徽章
- [ ] A2 待拍板角标：存在待确认任务时，「任务」按钮右上显示紫色数字角标，数量=待确认任务数
- [ ] A3 左栏（220px）：「工作流」组 → 电商新品上架（选中态黑底白字 + 任务数）→「6阶段 · 2拍板点」说明 → 直播带货/跨境选品（占位）→「通用」组 → 执行观测 / 设置
- [ ] A4 左栏折叠：点击「◀ 折叠左栏」→ 左栏收起为 48px 竖条（▶），主区加宽；点击 ▶ 恢复
- [ ] A5 工位栏（主区顶部固定）：标题「工位 WORKSTATIONS」+「＋ 添加 Agent」+ 3 张 Agent 卡（状态点 / 角色·名字 / 模型 / 待命或当前任务 / 「设置」按钮）
- [ ] A6 工位状态点：忙碌=紫色脉冲点，在线=绿点，待命=灰点（busy 时状态点有呼吸动画）
- [ ] A7 右栏聊天（280px）：工作群 / @美美 / @平平 / @波波 会话切换 + 消息流 + 输入框 + 发送
- [ ] A8 右栏折叠：底部「▶ 折叠聊天栏」→ 收为 48px（◀）；点击恢复
- [ ] A9 无横向溢出：1707px 宽下整页无横向滚动条

## B. 任务看板（对齐线框 renderBoard）

- [ ] B1 标题行：「任务看板」大标题 +「电商新品上架 · 6阶段 · 2拍板点 · N个任务」+ 右上「＋ 新建任务」按钮
- [ ] B2 四列：规划中 / 进行中 / 待确认 / 已完成，列头带任务计数
- [ ] B3 任务卡要素：#id + 衬线标题 / stageNote（如「主图设计完成 · 待你拍板」）/ 状态 tag（待你拍板·阶段 / 进行中·阶段 / ✓已归档）/ 负责人（头像+名字）/ 6 段 flowbar
- [ ] B4 卡片操作：规划中=「确认开工」；进行中=紫色脉冲点+「阶段名 推进中」；待确认=「采纳」「打回」按钮；已完成=「已交付 · 已归档」
- [ ] B5 点击卡片 → 进入该任务详情页（URL 变为 `#/task/<id>`），非导航跳转
- [ ] B6 空列显示「（空）」占位；空看板显示引导文案

## C. 新建任务（对齐线框 modal，两步）

- [ ] C1 点「＋ 新建任务」→ 弹窗第 1 步：任务标题 / 产品资料 / 目标平台 / 工作流选择 + 提示「确认后 AI 才开工」
- [ ] C2 点「下一步：确认内容」→ 第 2 步：内容摘要展示 + 「返回修改」/「确认并开工」
- [ ] C3 未确认前任务不进入看板、无 Agent 启动；确认后任务出现在「规划中」
- [ ] C4 Esc / 取消可关闭弹窗

## D. 任务详情页（对齐线框 renderTask）

- [ ] D1 「← 返回任务列表」回到看板
- [ ] D2 task-head：#id·标题·电商新品上架·由你创建 / 衬线大标题（≤2 行）/ 描述·目标平台
- [ ] D3 6 阶段条：需求对齐 › 卖点文案(拍板) › 主图设计(拍板) › 详情图设计 › 主管校对 › 交付归档，当前阶段黑底白字、已完成绿、未开始灰
- [ ] D4 tabs：「任务详情」|「内容交付 · 审批」（待确认时带审批后缀），激活 tab 紫色下划线
- [ ] D5 详情 tab-待拍板横幅（紫色焦点）：阶段·#id + 说明 + 「去内容交付页审批」按钮
- [ ] D6 详情 tab-非待拍板：「当前阶段：xxx」卡（含 stageNote）
- [ ] D7 活动日志时间线：创建任务/确认开工/进入阶段/阶段完成/采纳/打回/校对放行/校对回退/子任务完成，按时间排序
- [ ] D8 交付物概览：文案包（标题·卖点N条·版本）+ 各阶段图片（共N张·已采纳·待定·打回）
- [ ] D9 属性面板（右侧 280px）：类型/当前阶段/进度%/负责人/创建人/状态/创建时间 + 描述

## E. 内容交付 tab（对齐线框 renderDeliver / approve-box）

- [ ] E1 左右等宽两栏：卖点文案 | 图片交付
- [ ] E2 文案板块状态驱动：未产出(占位) / 生成中(脉冲) / 待拍板(采纳·打回) / 已采纳(仅「已采纳」标) / 已打回返工
- [ ] E3 文案成品卡：标题 + 5 条卖点 + 详情大纲 + 关键词标签
- [ ] E4 图片板块：主图 / 详情图 子 tab（带数量），每张缩略图带状态标（已采纳/已打回/待定）+ 待拍板时逐张「采纳」「打回」按钮
- [ ] E5 已确认图片按钮消失，仅显示状态
- [ ] E6 审批条（待确认时紫色焦点条）：待拍板阶段·#id + 说明 +（文案阶段）意见输入 + 「打回并发送意见」「采纳并推进下一阶段」
- [ ] E7 主管校对终审区（仅 review 阶段）：校对报告 + 「放行 → 交付归档」+ 回退目标选择 + 回退原因输入 + 「回退」

## F. 聊天（对齐线框 renderChat）

- [ ] F1 群聊：工作群（用户+全部 Agent），事件播报（阶段完成/待拍板/打回）显示为事件消息
- [ ] F2 私聊：@美美/@平平/@波波，仅该会话消息可见
- [ ] F3 消息展示：我的消息黑底白字右对齐，Agent 消息灰底带头像与时间
- [ ] F4 输入：回车或「发送」；连接中禁用；事件消息点击可跳转任务（若实现）

- [ ] H1 无任何 emoji 图标（🛍📺⚙📊👤⚠ 等均已清除）

- [ ] H3 字体三声部：衬线 Display（标题/卡标题/统计数字）、Sans Body（正文）、等宽 Metadata（#id/时间/状态/百分比）

- [ ] H5 无阴影默认；浮层（弹窗）阴影克制

- [ ] H8 焦点可见：键盘 Tab 聚焦有紫色 outline；reduced-motion 下动画关闭
