# 产品规格

- 品名：轻磁 Pro 磁吸充电宝
- 容量：10000mAh / 37Wh
- 有线输出：最高 22.5W
- 无线输出：磁吸 15W
- 接口：USB-C 双向
- 重量：198g
- 尺寸：104 × 68 × 16 mm

# 核心卖点

1. 磁吸即贴即充，无需插线，通勤场景单手可用。
2. 10000mAh 大容量，可为手机补电约 2 次。
3. 198g 轻薄机身，与手机同握不累手。
4. 支持边充边放，出差只带一个充电头。

# 电池与安全

采用锂聚合物电芯，循环寿命 500 次以上。具备过充、过流、过温、短路四重保护，通过 GB 31241 认证。

# 包装清单

充电宝 × 1、USB-C 数据线 × 1、说明书 × 1、收纳袋 × 1。

# 定价与渠道

- 建议零售价：199 元
- 大促价：159 元
- 主推渠道：天猫、抖音小店
