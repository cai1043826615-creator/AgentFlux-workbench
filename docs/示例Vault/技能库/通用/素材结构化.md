# 素材结构化

> 描述：把产品资料与每日热点素材整理成结构化 Markdown 的模板与规则：保留关键事实与来源路径、去噪与标注存疑，供工作流上下文直接消费。
> 分类：通用

## 一、结构化目标

整理后的素材要能被 Agent 工作流**直接引用**：每条信息可溯源、可检索、无口水话。整理 ≠ 改写，不添加原文没有的事实。

## 二、产品资料模板

```markdown
# <产品名> 资料卡（<日期>）
## 事实清单
- <一条可验证的事实，含具体数字/规格>（来源：<路径>）
## 卖点线索
- <从事实推导的候选卖点，标注「待文案确认」>
## 存疑
- <原文含糊/互相矛盾处，注明不采信原因>
```

## 三、热点素材模板

```markdown
# 热点：<主题>（<日期>）
- 摘要：<2 句内说清事件/趋势>
- 与本品关联：<可借势的角度；无关则写「无，仅存档」>
- 来源：<路径或信源名>
- 使用限制：<如「不得作为产品品类/功能依据」>
```

## 四、规则

1. **来源必填**：每条事实尾部保留来源路径，丢失来源的信息标注「来源缺失，待补」。
2. **去噪**：删口水话与营销腔，保留数字、规格、结论；不改写原意。
3. **存疑显式化**：矛盾信息并列呈现并标注，不替人做取舍。
4. **热点防线**：热点素材只做内容灵感，标注「不得作为产品品类/主体/功能规格依据」（与工作流热点注入约束一致）。
5. 产出一律进草稿区，不直接写 Vault。
