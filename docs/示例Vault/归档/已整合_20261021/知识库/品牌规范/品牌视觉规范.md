# 品牌视觉规范

> 描述：主图与详情图的视觉基线：配色、字体层级、版式与产品呈现规则，供设计师 Agent 保持系列产出的品牌一致性。

## 一、配色

- **主色**：品牌主色 1 个（大面积：背景/色块），辅助色 ≤ 2 个（卖点强调/信息分层）。
- **首图背景**：白底或浅灰（平台主图要求），场景图可用生活化暖调，但主色占比 ≥ 60%。
- **文字对比**：正文深灰 `#333` 以上，禁用浅灰小字；强调信息用主色，不用红绿同时抢焦点。

## 二、字体层级

- 层级 ≤ 3 级：钩子标题（最粗最大）→ 卖点短句 → 说明小字。
- 同图字体族 ≤ 2 种；数字信息可用等宽/表格化排版增强可信度。
- 最小字号以「手机端一屏可读」为准，禁用装饰性花体。

## 三、版式规则

- 留白：四边安全边距 ≥ 画面宽度 6%，文字不贴边。
- 对齐：同一图内只用一种对齐基准（左对齐或居中），不混用。
- 系列一致：详情图组共用同一模板（标题位/卖点位/参数位固定），换内容不换骨架。

## 四、产品呈现

- 产品图不拉伸、不镜像变形；角度统一（同组图同机位视角）。
- 白底图：纯白背景 + 柔和投影；场景图：真实使用场景，光线自然。
- 禁止：描边发光特效堆满、图标堆砌、与卖点无关的贴纸元素。
