# 品牌手册

> 描述：品牌调性、话术边界与表达规范：文案的语气基线、禁用表达与背书句式，供文案 Agent 在电商与小红书两条业务线统一品牌声音。

## 一、品牌调性

- **专业但不端着**：说人话，讲清事实与利益点；不堆形容词，不端架子。
- **具体压倒夸张**：「10 秒出汁」永远好过「极致体验」；一切卖点可验证。
- **克制**：一个卖点说一次说透，不重复轰炸；感叹号每篇 ≤ 2 个。

## 二、语气基线（按场景）

| 场景 | 语气 | 例 |
| --- | --- | --- |
| 电商标题/卖点 | 干练、参数化 | 「食品级材质 380g 随行」 |
| 详情叙述 | 平实、场景代入 | 「通勤地铁上，拧盖即饮」 |
| 小红书笔记 | 朋友分享口吻、第一人称 | 「用了两周，最惊喜的是…」 |
| 售后承诺 | 明确、无推诿 | 「7 天无理由，运费我们出」 |

## 三、话术边界（禁用）

- 绝对化与医疗功效类表述（各平台违禁词清单为准）。
- 贬低竞品、虚构销量/评价数据、「国家级/最高级」类用语。
- 过度承诺：「彻底」「根除」「永久」一律改为可验证表述。

## 四、背书句式

- 材质背书：「食品级 XX 材质，通过 GB 4806 检测」（无检测依据则写「食品级接触材质」，不编标准号）。
- 服务背书：只写真实政策，不虚构「全国联保」等未提供的服务。
