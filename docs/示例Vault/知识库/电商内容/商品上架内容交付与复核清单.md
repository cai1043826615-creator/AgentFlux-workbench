# 商品上架内容交付与复核清单

## 交付包
包含任务编号、商品品牌/SKU/变体、渠道和类目；标题候选与选择理由、关键词来源及日期；主卖点和事实证据定位；详情页分屏稿、图中文字、图片 Brief 与素材来源；属性填写表、适配/限制/包装信息；价格优惠和售后审批记录；待补问题、审核人、版本号、计划上线日期。

## 内容检查
- [ ] 品名、SKU、型号、颜色、套装和渠道对应同一商品
- [ ] 数字、单位、材质、认证和效果有证据
- [ ] 标题、主图、属性、详情和后台字段一致
- [ ] 重要限定与卖点相邻，没有藏在难读小字中
- [ ] 没有虚构评价、销量、测试、资质、奖项或用户故事
- [ ] 价格、门槛、日期、赠品、库存均为当前记录
- [ ] 适配、包装、售后和安全提示完整
- [ ] 素材具备版权、肖像和商标使用许可
- [ ] 各平台版本分别核对字段、类目和规则
- [ ] 保存最终稿、证据快照、复核人和时间

## 状态定义
草稿：可继续修改。待补资料：关键事实缺失，禁止发布。待复核：内容完整但未签核。可交付：内部验收通过，仍需商家在后台最终确认。已发布：记录线上链接、发布时间和版本。已撤回：记录影响范围、原因和替代版本。

“可交付”不代表平台审核通过或法律保证。发布操作者仍须查看当前后台提示和真实预览。发现错误先暂停相应素材，再登记影响渠道、更正责任与完成时间。

## 缺陷等级和处理
阻断级：SKU错、关键参数无证、价格或权益失实、图片与包装不符、版权未获许可、重要限制缺失。未修复不能交付。高优先级：标题难以识别商品、适配条件不清、移动端关键字不可读、后台字段冲突。修复后需重新做渠道预览。一般级：非关键措辞、标点或非主要布局问题，登记责任人后修订。等级仅用于内部排期，不代表监管或平台风险结论。

## 交接验收
接收人按照文件列表逐个打开，并检查文件是否完整、命名是否明确、版本是否一致、链接是否可用。发布后回填真实页面链接和截图，保留与内部稿对应的版本号。若页面发布时被后台自动裁切、替换属性或改价，保存最终线上状态，而不是把交付包当作实际发布结果。
## 上架后巡检
交付后由非制作人打开实际商品页面，对照 SKU 变体、首图、详情图顺序、属性表、价格权益、包装数量、售后说明与最终审核稿。检查移动端和桌面端的首屏信息、图像裁切、加载失败、文字清晰度以及页面跳转。记录平台、店铺、商品链接、核验时间、核验人和截图；页面缓存或审核替换造成差异时，重新提交相应素材。

## 交付包索引
每个交付包提供一页索引，列出最终发布文件、尺寸、版本、状态、事实卡版本、授权凭据位置、审批人、适用渠道和失效条件。临时预览图、水印样稿和旧版应分开存放并标识不可发布。若商品资料在交付后变化，关联变更单并重新检查依赖素材，而不是只替换最先发现的一张图。
## 上架故障分流
图片上传失败先核对格式、尺寸、文件完整性和平台返回信息；图片审核未通过则保存平台原因并转对应审核人；页面信息显示旧值时确认是否存在缓存、变体切换或后台延迟。每类问题记录复现步骤和平台截图，修复后由另一个账号或无缓存页面复验。不要因文件在后台显示“成功”就假定前台已生效。
## 交付签收
制作人提交后，接收人核对文件数量、命名、平台尺寸、事实卡版本和审批状态；缺项逐项退回并保留签收时间。口头确认不能代替交付记录。
