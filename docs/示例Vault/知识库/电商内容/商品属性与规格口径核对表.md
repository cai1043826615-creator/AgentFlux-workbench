# 商品属性与规格口径核对表

## 为什么要单列口径
同一参数可能出现标称值、额定值、典型值、最大值、实测值或容差范围。数字相似不代表含义相同。标题、属性、图中文字和客服答复应复用同一经过批准的字段，不能由各岗位自行换算或四舍五入。

## 字段映射
| 字段名 | 规格原文 | 后台属性名 | 值/单位 | 测量或定义方法 | SKU/变体 | 证据位置 | 允许表述 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

对容量、尺寸、重量、功率、承重、材料、适配范围、包装数量和保修等关键字段逐项填表。无对应平台字段时，注明“无对应字段”，不要塞到错误属性里。

## 口径核对
确认单位换算有明确来源；标注外形尺寸的长宽高方向；测量值包含或不包含突出部件；材质是主体还是局部；兼容条件涵盖设备、配件和版本；额定与峰值的定义明确。允许误差和生产公差需用正式规格口径。

## 后台发布
发布前把本表与当前商品后台的类目必填项并排核查。平台属性变化时记录公告链接、生效日、受影响 SKU 和补录责任人。后台强制字段不能由文案任意填补；没有准确值时暂停发布并追问产品负责人。

关联[[商品事实与宣称证据总则]]与[[电商内容规范]]。

## 数字字段的二次校验
对每个数字记录原始单位、显示单位、精度和转换公式来源。禁止随手把英寸转厘米后取整，把最大值写成常规值，把实验室条件写成日常保证。多变体共用页面时检查选择器切换后参数是否同步。属性不适用时按后台要求处理，不以“0”替代空值或不适用。

## 复核会签
运营确认后台字段和类目，产品确认规格口径，内容确认文案引用，发布人确认预览结果。若字段由平台自动填充，截图保存来源并核对是否来自当前 SKU。字段变更后同步更新事实卡、关键词映射、图文和客服FAQ。
## 字段级核对方法
按平台字段逐行映射品牌内部资料：商品名、型号、颜色、材质、尺寸、重量、数量、包装清单、适配范围、使用限制、保修与售后。记录来源文件、版本、页码/字段、SKU 变体和复核状态。单位先统一再比对，保留原始单位与换算过程；包装数量要区分单件、套装和赠品。商品标题、属性后台、详情文案出现同一数值时，全部引用同一批准值。

## 不一致的处理
后台旧值与当前资料冲突时不采用“看起来更合理”的一方；先冻结相关字段及其衍生文案，交商品负责人确认生效时间和受影响变体。确认后记录旧值、新值、证据、更新人及页面核验链接。缺少字段不得以竞品页面、图片比例、型号命名或 AI 推测补齐；可以先发布不包含该字段的内容，前提是其余信息仍足以准确识别商品。
## 变体抽核示例
同款不同颜色若共用页面，先确认型号、尺寸、材质、包装和适配是否确实一致；颜色差异仅能影响对应字段，不能凭“同一链接”推断所有属性共用。套装页面逐个核对各组件数量，赠品与标准包装分开登记。对照后台导出与商品实物标签，若字段名称不同，建立明确映射并保留解释。复核发现错值时，列出所有引用此字段的标题、图片和问答，统一更新并在线复验。
## 复核留痕
复核表同时保存后台字段导出和依据资料的版本号；发生人工换算时保留公式、原始数据与舍入规则。审批完成后锁定该批字段的使用版本，后续变更另开记录，避免覆盖历史依据。
## 变体回归
每次平台模板或商品选项调整后，重新抽查所有变体的字段映射；重点确认默认选项、组合装和缺货变体没有继承错误属性。复核结果关联变更单。
