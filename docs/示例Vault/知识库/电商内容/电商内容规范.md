# 电商内容规范

> 版本 1.0 · 发布 2026-10-21 · 复核责任：电商内容负责人 · 计划下次复核：2026-11-21。平台公告或适用法律变化时立即复核，不等月度日期。

## 1. 适用范围
用于天猫、京东、抖音电商、小红书店铺等渠道的标题、卖点、详情页、主图文字和短视频脚本。平台字段、字符限制、类目资质和审核口径不同；每个渠道都要检查当前商家后台，不能把一个平台模板当作全平台规则。

## 2. 生成前输入
提供准确 SKU 与变体、已核验事实卡、目标平台/类目、目标用户和场景、后台属性、促销及售后口径、素材授权、交付格式和负责人。输入缺失时先产出资料缺口清单，不把缺资料任务写成完整商品介绍。

## 3. 信息层级
1. 商品身份：品牌、品类、型号/变体和必要属性。
2. 核心购买理由：一条经核验的主卖点。
3. 支持证据：规格、结构、测试或可核实服务。
4. 使用与适配：对象、条件、限制、配件和操作方式。
5. 交易信息：价格、门槛、赠品、库存、配送和售后。
6. 风险提示：安全使用、兼容边界或法定披露。
标题、主图、属性、详情、视频和直播应一致；产品变更后同步检查所有触点。

## 4. 标题与搜索词
先找用户实际搜索的品类词，再加入相关且可证的属性。每个词须与商品相关，并能在当前后台或证据中对应。不得塞竞品品牌、无关热词、未确认型号或优惠，不以重复同义词占字符。长度按具体平台和类目核对。保存词源、日期、范围；工具估值不是销量或排名结果。

## 5. 卖点和详情页
每条按“事实—条件—用户意义”组织。首屏让人认出商品并理解价值；后续解释核心功能、证据、使用方式、适配条件、规格/包装、售后和购买提醒。重要限制与相关卖点相邻，不用小字否定醒目主张。属性按当前后台必填项准确填写。促销写清期限、门槛、适用范围和叠加规则，过期即下线。

## 6. 宣称与素材风险
效果、比较、检测结论、销量、评价、排名、认证和第三方引用都需证据。不得虚构体验、稀缺、资质或奖项。绝对化词要结合语境与事实判断；词库扫描只是提示，不能替代审核。广告主需对广告真实性、准确性和合法性负责。

## 9. 生产作业顺序
资料对齐 → 关键词与用户问题整理 → 标题和卖点草稿 → 详情结构 → 图片文案/脚本 → 逐条事实复核 → 渠道预览 → 负责人放行。每一步交接必须附前一步的版本号；禁止文案和视觉并行使用不同的事实卡。任一关键资料待核验时，任务输出为“待补资料”，不得把空缺自动填成模型推测。

## 10. 常见返工原因
商品名或型号与后台不同；电商标题被关键词塞满而读不通；主图说“套装”但实际只包含单件；使用场景让人误解为产品有额外配件；详情页写了旧促销价；同系列不同容量复用同一参数；脚注太小而主标题形成过强承诺。返工时标注原问题、影响素材和根因，更新对应模板，避免只修单张图。

## 11. 复核会记录
每月复核由内容、商品运营和渠道负责人分别确认：规则源是否仍有效、字段是否变化、最近一次拒审/投诉原因、待处理内容数量、过期活动资产数量和下一次负责人。版本升级时更新文档头、变更表和影响范围；只改日期而没有说明核对项，不算完成复核。
