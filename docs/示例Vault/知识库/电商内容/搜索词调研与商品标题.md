# 搜索词调研与商品标题

## 目标
让真实用户能找到商品，并快速辨认它是什么、适合何种需求。标题不是把词库塞满字符；每个词都要相关、准确、可读，并能在当前平台字段中展示。

## 词源采集
从平台搜索联想、商家后台搜索/广告报告、客服高频问题、评论自然表达和站内类目词收集候选。外部工具仅作研究线索。记录平台、类目、查询日期、来源、时间范围、词原文、意图、相关度、证据状态和限制。

词分为品类词、结构/功能词、场景词、属性词、需求词和品牌词。功能与属性词须有当前 SKU 证据；品牌词须自有或获授权。剔除无关热搜、竞品名称、其他型号、无证功效和不匹配节日词。

## 意图与优先级
标注购买对象、用户任务和决策阶段。优先顺序为相关性、准确性、可读性、搜索机会。未验证的热度分数不能写成排名或转化保证。

## 标题组装
基本结构：品牌/型号（需要时）+ 核心品类词 + 关键属性 + 有证差异点 + 变体信息。按平台要求调整顺序。删除重复词、堆叠形容词、无关品牌、引流话术及未经审批的价格。字符上限按目标平台和类目后台确认，不能照搬另一个渠道。

每个候选保留组成拆解和事实来源。A/B 版本一次只改一类因素，并记录版本、投放时间、流量渠道和观察窗口。没有真实数据时只称候选标题，不称高转化标题。

## 复核
- [ ] 品类、SKU 和变体正确
- [ ] 属性有证据且与后台一致
- [ ] 每个词都和商品相关，不引入竞品或错误导流
- [ ] 标题自然易读，不像词串
- [ ] 促销价格未混入常驻标题
- [ ] 长度、类目格式和禁限词按当前后台复核
- [ ] 记录词源日期，过期数据不沿用

示例必须引用当前事实卡；演示内容用待核验占位，不虚构规格。关联[[商品事实与宣称证据总则]]和[[电商内容规范]]。

标题测试前记录基线、渠道、类目、广告流量占比、促销状态、观察时间和主要指标；明确哪些变量固定。不能用不同季节或不同商品的数据直接比较标题。若展示量太少，结论写“样本不足”，继续收集，不挑一个更好看的指标宣布胜出。

## 候选标题打分
为每项 0–2 分：商品识别是否明确、关键词是否真实相关、已核验属性是否正确、读起来是否自然、是否含风险词。任何事实错误或不相关品牌词直接淘汰，不因总分高而放行。剩余候选由运营检查后台字数与类目规范，并保留未选理由供复盘。
## 搜索词清洗与证据
每个候选词记录来源、采集日期、对应用户意图和适用 SKU。剔除无关品牌词、无法证明的材质/功效词、竞品商标和误导性热词；同义词合并前保留原词，避免丢失用户语境。关键词工具的热度仅反映其统计口径，不能作为需求真实性、销量或购买意愿的直接证明。

标题交付前核对平台类目要求、字符限制、特殊符号、品牌授权和变体差异，并在真实后台预览截断效果。测试报告写清改动版本、固定变量、观察周期、流量结构和样本限制；标题带来更多点击但用户搜寻目标与商品不符时，应视为相关性下降并回退。
## 标题审核的反向检查
审核者只看标题和商品实际信息，尝试回答“用户是否会误以为包含额外配件、适配更多设备、具备更强性能或享有某项权益”。若容易产生错误预期，缩减词语并回到证据。对平台自动拼接品牌、变体或促销标签的页面，还要检查组合后的完整标题是否重复、截断或形成新的绝对化含义。
