# 品牌表达与语气指南

## 品牌表达原则
### 先讲清事实，再讲用户收益
每段回答一个真实问题：这是什么、怎么使用、适合何种场景、如何判断是否适配。先找到事实，再翻译成用户收益；不把“不知道”包装成“升级体验”。

### 专业但易懂
用常见词解释专业事实；首次出现参数时交代单位和影响。避免参数堆砌、行业黑话和假装亲测。亲切不等于编造体验。

### 克制而有重点
一个核心卖点讲清楚后，不在标题、正文和图中文字反复轰炸。每个模块设一个主信息。感叹号、全大写和空泛形容词保持克制，让事实和场景承担说服力。

### 尊重用户选择
说明适用范围、限制条件、价格门槛、配件数量和售后规则。不要制造虚假焦虑、稀缺、竞品贬低或“不买就会损失”的暗示。

## 渠道表达
| 场景 | 表达方式 | 避免 |
|---|---|---|
| 电商标题 | 直接、可检索、属性完整 | 关键词堆砌、无关热词 |
| 电商卖点 | 功能事实、适用条件、用户意义 | 先承诺结果，再用小字免责 |
| 商品详情 | 由价值到证据、规格、限制与服务 | 重复卖点、把限制藏在末尾 |
| 小红书笔记 | 真实创作者语气，讲具体问题和过程 | 模拟真实用户或捏造长期体验 |
| 售后答复 | 同理、明确、说明处理路径 | 推责或越权承诺赔付时限 |

## 可复用句式骨架
- 事实型：某功能在已确认条件下，为某类使用需求提供帮助。
- 场景型：在真实场景中，产品完成可验证的动作，帮助用户完成某一步。
- 限定型：在已确认条件下支持某功能；其他设备或场景需核对规格。
这些是组织句子的骨架，不是可以填入任意结论的承诺模板。

## 禁止的写作捷径
1. 不将模型生成的第一人称体验写成真实用户体验。
2. 用户反馈、实测、销量、排名、专业推荐都要有可查记录与必要授权。
3. 不用零风险、永久、全网最好、行业第一等无范围保证。
4. 价格优惠、限量、售后无忧不是常驻语句，须查当前政策。
5. 不以高级、极致、颠覆等修饰词替代产品证据。
6. 不冒充检测机构、专家、医生、官方或消费者。

## 发布前声音检查
非专业用户能否复述？每项事实能否追溯？场景是否真实？限制是否紧邻卖点？删去形容词后内容是否仍有价值？若答案是否，补证据或重写。

## 表达改写练习
| 原始句 | 问题 | 推荐改法 |
|---|---|---|
| 极致稳固，任何桌面都不晃 | 绝对化、无条件、缺少测试 | 先确认桌面和负载条件，再描述对应测试结果 |
| 每个人都需要的随身神器 | 用户范围泛化、空泛 | 说明适用场景和实际功能，不替用户做决定 |
| 我已经用了三个月，真的值得 | 若无真实作者记录则为伪造体验 | 改为品牌说明式介绍，或请真实作者提供素材 |
| 全网最低，错过再等一年 | 动态比较、虚假稀缺风险 | 仅在有完整价格基准和活动审批时使用限定表达 |
| 质量超好，安全放心 | 没有可核验信息 | 列出与 SKU 对应的材料、测试或说明书内容 |

## 语气验收表
分别用“事实是否准确、用户是否听得懂、限制是否显眼、是否像真实账号身份、是否能删掉空泛修饰”五项打勾。品牌官方内容不冒充个人日记；小红书内容不冒充普通消费者；售后答复不以情绪缓和替代明确处理步骤。出现歧义时优先增加条件，而不是加“仅供参考”来免责。
