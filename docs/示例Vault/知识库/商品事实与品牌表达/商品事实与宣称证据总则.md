# 商品事实与宣称证据总则

## 目的与边界
本文件是电商与小红书内容生成前的事实闸门，规定哪些信息可以写、需要什么证据、遇到缺口如何处理。工作流只读取经业务负责人确认的事实，不根据图片、同类商品、模型常识或旧宣传语补齐缺失规格。它不是产品说明书，也不替代法务审查。

## 事实状态
| 状态 | 含义 | 内容处理 |
|---|---|---|
| 已核验 | 当前 SKU 的说明书、检测报告、标签、合同或后台记录能支持该字段 | 仅在证据适用范围内使用 |
| 待核验 | 旧文档、聊天记录、样例、截图或没有来源的口述 | 不作为正式卖点，只用于追问 |
| 推导值 | 从容量、重量、比例或其他字段计算得出 | 不发布，先由产品负责人确认口径 |
| 失效/禁用 | 过期、SKU 不符、错误、无法证明或可能误导 | 停用并记录原因 |

核验需同时确认商品型号/SKU、资料版本、出具主体、适用规格、单位、有效期及文件位置。同系列不同颜色、容量、套装或代际不得共用未经确认的参数。

## 证据优先级
1. 当前 SKU 的法定标签、说明书、检验检测报告、认证文件及正式规格书。
2. 当前有效的采购合同、品牌授权、售后政策、价格与促销审批记录。
3. 产品负责人书面确认，并能追溯到原始材料。
4. 内部旧稿、历史页面、评论和竞品信息只能作为线索，不是商品事实证据。

截图需看清页面主体、日期和上下文；裁剪片段只作线索。引用第三方测试、调查、排名、销量或评价时，保存原件、样本与时间范围，并核对适用对象。

## 宣称登记
每条影响购买决定的陈述记录：编号、原始表述、标准事实、SKU、证据路径、出具者、日期、适用条件、可用渠道、审核人、到期日、状态。同一证据不能自动扩展到另一规格或渠道。图文和口播均应能回溯记录。

## 生成闸门
1. 明确 SKU、渠道、目标人群、内容类型、素材和资料截止时间。
2. 把输入拆成参数、功能、效果、比较、认证、服务、价格、评价八类。
3. 每个数字、比较级、性能结果和背书语逐条找证；缺证标待核验。
4. 把事实翻译成消费者能理解的收益，但不扩大证据范围；限制与对应卖点相邻。
5. 交付附已用事实、未用事实、待补材料清单；待核验内容不进入成稿或设计图。
6. 上线前核对当前 SKU 后台、页面与素材的一致性并记录最终版本。

## 常见错误
- 图片看起来薄，不能推出具体厚度；需规格书或测量记录。
- 支持快充要明确接口、协议、功率条件和适配对象；不能只凭宣传口号。
- 充电次数涉及测试设备、电池容量和损耗，不可从 mAh 简单相除。
- 认证需核对型号、证书主体、标准版本和有效状态。
- 用了两周、用户都说好需要真实记录或授权，不可让模型拟造第一人称。
- 限时价、全网最低、买赠等要有当前审批和活动规则。

## 规则来源
广告主需对广告内容真实性、准确性、合法性负责；引用第三方数据时保存出处和适用范围。绝对化用语需结合指向对象和语境判断，不能只靠关键词表机械放行。

## 证据审核示例与风险分流
以“续航更久”为例，审核人先追问“比较对象、测试条件、结果定义、测量设备、样本数、环境和版本”。若只找到一张没有测试方法的宣传图，状态仍是待核验。若拿到实验室报告，报告只支持其注明的样品和条件，不能自动转成所有用户的体验保证。

风险可按影响程度分级：低风险是品名、颜色等识别字段；中风险是尺寸、材质、适配、包装和服务；高风险是安全、健康、认证、对比优势、统计结果、价格承诺和可能改变购买决定的效果。高风险字段必须逐条核验并双人复核。低风险也要确认 SKU，不能因风险低而沿用错款数据。

## 变更控制
产品变更、供应商切换、检测报告更新、平台规则变化或活动结束时，责任人建立变更记录：变更对象、影响 SKU、开始生效时间、旧证据失效时间、涉及内容渠道、需要下线的页面、审核人和完成状态。任何旧版本仍在线时，变更项标记为“传播中”，不可把新资料直接当成已全渠道同步。复核结束后保留旧版本用于追溯，禁止静默覆盖。
