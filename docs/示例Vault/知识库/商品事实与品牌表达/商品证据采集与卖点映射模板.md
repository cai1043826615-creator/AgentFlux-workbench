# 商品证据采集与卖点映射模板

每个 SKU 的首次内容任务和重大版本更新都应复制本模板到任务资料中填写。模板本身不是某个商品的事实卡。

## A. 任务信息
- 品牌/正式品名：
- SKU、变体、商品后台链接：
- 目标渠道、类目和内容类型：
- 版本、负责人、任务日期：
- 目标用户、场景、期望动作：
- 不可改变的事实、限制与禁用项：
- 活动时段、店铺、门槛与叠加条件：

## C. 事实到卖点映射
| 原始事实 | 证据定位 | 适用条件 | 用户问题 | 可表达收益 | 不可外推内容 | 核验人/日期 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

每条用户收益必须能对应事实。只证明具备某功能，就不能扩写成效率、耐用性、舒适度或结果改善。

## D. 状态定义
已核验：允许在标注范围内写入。待核验：留空或返问负责人。失效：过期或 SKU 不匹配，停用并注明替代资料。禁用：已知错误或风险高，记录原因避免复用。

## E. 交付闸门
- [ ] 任务指向具体 SKU 与变体
- [ ] 数字、认证、比较和效果承诺可追溯
- [ ] 价格、促销、赠品、库存和售后为当前记录
- [ ] 图片和评价有授权，样例没有冒充真实用户
- [ ] 待核验项未进入标题、图中文字或口播
- [ ] 未覆盖问题和所需材料已交给负责人

## 示例：如何填写一条映射
原始事实：规格书注明某接口支持某一输出协议。证据定位：规格书第 X 页、版本号和发布日期。适用条件：目标 SKU、所用线缆、供电设备。用户问题：外出补电时是否需要携带另一条线。可表达收益：在资料确认的组合下，可使用对应线缆连接。不可外推：不能写所有设备都能达到最高功率，也不能从接口名称推断兼容性。核验人：产品负责人及复核日期。

## 缺资料时的任务分流
若缺商品身份，暂停生成；若只有个别非关键属性缺失，可先写不含该属性的内容框架；若缺价格或活动信息，可先完成常规页面，不生成促销图；若缺授权，可使用纯文字版 Brief，不能先生成带人物、用户评价、Logo 或版权图片的视觉稿。任务状态、缺失责任人和预计补齐日期须回到工作流任务卡，避免资料问题被误认为 AI 生成失败。
## 证据质量与复核记录
同一卖点可能需要多份材料共同支持：规格表回答“标称值是什么”，测试报告回答“在什么条件下测得”，说明书回答“允许怎样使用”，商品图只用于核对外观和部件。登记材料名称、版本、页码/字段、适用 SKU、样品批次、出具方、日期、限制和复核人。网页截图应同时留页面地址与采集日期，不能只保存裁切后的结论。

评审时逐句检查“事实—用户收益—表达强度”是否匹配。事实为特定条件下的测试值，收益就要保留条件；主观体验不能改写成客观性能；单个样品观察不能概括全部批次。发现冲突时并列记录各来源与负责人结论，不自行挑选更有利的一份。
