# 小红书图文脚本与分镜清单

## 脚本卡
笔记主题：______；作者/账号身份：______；SKU及品牌关系：______；目标读者：______；读者问题：______；可核验资料：______；真实体验记录：______；披露要求：______；需避免的暗示：______；发布日期：______。

页数根据内容决定。封面负责准确概括主题，不夸大结果；每页有一个主信息，图文顺序能独立讲清楚。真实体验内容须由作者提供原始素材，品牌说明内容不得用“我亲测”包装。

## 拍摄/生成约束
核对商品型号、颜色、部件、配件数量和商标；如出现手、人物、家庭或工作场景，确认是否真实和有授权。生成素材不能伪造商品测试结果、评论截图、平台界面或认证标志。图中文字必须与正文一致，移动端检查裁切和可读性。

## 完稿验收
标题、封面、正文、商品组件和披露信息统一检查；每项事实回溯证据；不适用范围清楚；不存在站外导流；素材授权记录可查。关联[[小红书内容规范]]和[[视觉制作与质检规范]]。

## 拍摄现场执行单
开拍前逐镜确认商品版本、道具、空间、光线、出镜授权、画面中可读品牌/商标和隐私信息。每镜记录景别、机位、动作、时长、环境声、屏幕文字和需要的补拍；涉及对比时保持条件一致并说明差异来源。生成画面须标明“示意/渲染”等内部属性，评审时核对接口、比例、部件位置与实物参考一致。

## 剪辑与导出复核
粗剪先核对叙事和证据，精剪再检查字幕、音乐授权、封面裁切、敏感信息遮挡及披露呈现。逐张图检查文案没有被 UI 遮住、关键信息没有只出现在一闪而过的镜头。导出后在目标设备预览最终文件；不得以脚本通过作为成片验收。修订时标出时间码/页码、问题类型、责任人和复核结果。
## 一个六页图文的组织方法
可按“提出具体问题—说明判断条件—展示操作步骤—补充已确认事实—说明限制—总结下一步”组织，但页数服务于信息，不要求每篇固定六页。逐页写一句读者此页应理解的内容；两页承担同一任务时合并，缺少证据的页改为提示待核验或删去。最后用缩略图预览全套节奏，检查色彩和构图变化不会破坏阅读顺序。
## 交付命名
成片、封面、字幕稿和原始素材使用同一任务编号与版本号；列出可发布版本和仅供评审的预览文件。发布人按清单选取，避免误用旧字幕或无披露版本。
