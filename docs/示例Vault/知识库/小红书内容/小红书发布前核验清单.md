# 小红书发布前核验清单

## 身份与内容
- [ ] 账号身份、品牌关系和商业合作披露符合当前要求
- [ ] 标题准确描述正文，不堆无关关键词
- [ ] 第一人称体验真实，作者有素材、记录和授权
- [ ] 商品功能、价格、资质、效果、比较和评价有证据
- [ ] 样本、测试、数据、引用标注来源及适用范围
- [ ] 图片和视频对应当前 SKU，不误示配件、外观或效果

## 平台与互动
- [ ] 当前账号、类目和内容形式适用的规则已核对
- [ ] 发布字段、商品组件、首图和标题符合后台提示
- [ ] 没有站外联系方式、私下交易诱导或规避审核表达
- [ ] 评论引导自然，不组织虚假互动或刷评
- [ ] 隐私信息已处理，音乐、字体、肖像和图片许可有效

## 留痕
记录内容版本、账号、发布时间、关联商品、事实卡版本、规则页面及复核日期、负责人和发布链接。规则发生变化后复核仍在线内容；发现问题登记暂停、修正或撤回结果。

此清单是内部复核工具，不能替代平台审核。关联[[小红书内容规范]]与[[视觉制作与质检规范]]。

## 必须暂停发布的情况
商品型号不明确；第一人称体验没有真实作者或记录；商业关系无法确认；关键参数、效果、资质或价格无证据；素材授权不明；图文对商品外观/包装产生误导；限制条件在画面不可读；目标账号或类目规则无法定位；存在站外交易引导或隐私泄漏。暂停时写明缺失证据和责任人，不能只留一句“注意合规”。

## 发布后回看
发布后保存实际页面、发布时间、商品链接和平台提示。发现错误立即评估影响范围，按负责人流程更正、隐藏或删除；不通过新发内容掩盖旧稿风险。评论区出现事实纠错时先核验，再决定公开更正和更新资料卡。

## 复核签字区
事实复核人：______；账号身份/披露复核人：______；图片授权复核人：______；发布账号：______；规则页检查日期：______；未解决问题：______。阻断项未清零时不得由发布人自行勾选放行。若不同岗位意见冲突，记录证据和负责人决定，不通过删掉意见来达成“全绿”。

## 发布后回看项
发布后确认封面裁切、商品组件、披露标签和链接均呈现正确；保存页面截图及链接。若平台审核修改、提示违规或内容被限制，保存平台原因和时间，先分析规则及事实，再决定修正方式。旧版本仍可见时，建立下线跟踪记录。
## 发布责任与证据留档
发布人按实际发布账号逐项核验，而不是只审导出的文案文件。保存最终标题、正文、图片顺序、商品链接/组件状态、商业关系披露、发布页面截图和审核反馈，并记录内容版本、负责人及日期。发布前确认账号具备相应权限；涉及合作、赠品、佣金或品牌提供素材时，按当前平台规则核对清晰、可见的披露方式。

## 退回和更正
事实、授权、披露、隐私或平台规则任何一项不明确，状态设为“待补材料”并指出具体缺项，不用“先发再改”替代审批。收到平台提示后保留提示原文、发生时间和内容链接；由账号负责人判断申诉、编辑、隐藏或下线，内容团队不得自行猜测处罚原因。更正完成后复查仍可访问的旧笔记、置顶内容及关联评论。
## 发布前五分钟复核
由发布人从手机预览最终稿：第一屏是否准确、图片排序是否正确、文字有无错别字或遮挡、商品组件和链接是否指向正确 SKU、披露是否清晰。再检查作者身份、授权、事实来源、内容有效期和评论区承接方式。发布后马上打开真实页面核对实际呈现；若与审核稿不符，暂停投放并告知负责人，不只在本地修正文件。
