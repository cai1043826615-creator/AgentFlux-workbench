# 笔记标题开头与叙事结构

## 标题任务
标题应准确告诉读者主题和价值，不承诺正文无法证明的结果。可从具体场景、问题、选择条件、步骤或经验教训切入。标题候选需要与图片、正文、商品信息一致，避免不相关热词、过度标点和误导性悬念。

## 开头方式
- 场景问题：先交代“在什么情况下遇到了什么问题”。
- 选择条件：说明做选择时最在意的两个因素。
- 操作入口：先告诉读者这篇会解释哪一步。
- 经验总结：仅在作者有真实经历和可复核素材时使用。

## 正文结构
1. 读者是谁、场景是什么；
2. 问题或目标是什么；
3. 方法、产品功能或选择依据；
4. 具体步骤、观察或证据；
5. 限制、适用范围和注意事项；
6. 结论及下一步信息。

一篇笔记只保留一个主问题。涉及商品时，将产品事实与个人感受分开；没有第一手体验就改为说明型内容，不拟造口吻。数据、测评和比较要写清来源、条件、时间及样本边界。

## 视觉配合
封面只提炼主题，不夸大结果；图序与正文一致。把关键信息分散到清晰、易读的画面，不将完整长文塞进封面。图中商品、部件和包装须与实际 SKU 匹配。具体尺寸及标题限制查当前发布后台。

## 复核清单
- [ ] 标题能准确概括正文
- [ ] 开头没有虚构身份或经历
- [ ] 每个结论有依据或明确为个人感受
- [ ] 商品关联自然且适用条件清楚
- [ ] 图片文字与正文、商品页一致
- [ ] 没有站外引流、虚假互动或误导承诺

## 结构示例与反例
场景型标题只说真实发生的场景；问题型开头提出本文能回答的问题；步骤型内容应确保步骤可执行且来源可靠；比较型内容写清比较对象和条件，不能只选对品牌有利的维度。避免“用了才知道”“千万别买”“后悔没早买”等没有证据的强情绪标题。

## 图文脚本对照
脚本每段标注口播/画面/字幕/事实编号/拍摄素材/剪辑提示/限制说明。画面先于字幕理解时，仍需确保没有制造错误商品印象。发布前把笔记标题、封面、正文、商品组件和评论引导放在同一预览中审阅，逐项确认承诺一致、披露清楚且无站外交易暗示。

## 候选对照示例
场景标题：“在狭窄桌面整理设备时，我先核对这几个尺寸”——仅当作者真实经历时用第一人称。说明型标题：“折叠支架选购前，先确认桌面空间与设备尺寸”——适合品牌知识说明，需确保正文覆盖这些核对项。避免“这款支架谁用谁夸”等无法验证的口碑断言。

## 标题评审
逐项检查主题对应、读者明确、结果可兑现、商品关系透明和限定信息充分。测试不同标题时保留图片和正文不变，并说明发布时间、曝光来源及观察期。若标题点击提升但阅读后快速退出或评论指出误导，应视为负面信号并重写。
## 阅读体验核对
把标题、封面、首屏和结尾连起来阅读，确认用户在进入正文后能迅速理解主题，并在内容结束时得到标题承诺的答案。首屏不应制造正文无法证明的紧迫感或结果暗示；开头可以来自真实问题、明确场景或步骤，但不能伪造亲身经历。结尾优先总结判断方法和适用限制，商品行动提示与内容主题保持相关。

## 版本实验记录
标题或封面测试一次只改变可辨识的变量，保存版本号、发布时间、账号、流量来源、观察窗口、样本量和目标指标。查看点击之外的阅读完成、收藏、评论质量、投诉及退货反馈。数据不足时标记“暂不判断”；指标上升但误解增加时，不作为胜出版本。复盘结论需写明适用账号、主题和时间范围。
