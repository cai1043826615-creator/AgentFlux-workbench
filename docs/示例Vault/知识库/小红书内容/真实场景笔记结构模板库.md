# 真实场景笔记结构模板库

> 模板提供结构，不提供虚构经历、结论或商品事实。使用前确认作者身份、素材来源和事实状态。

## 模板 A：问题说明
标题：某具体场景下，如何处理一个常见问题
开头：交代真实场景和问题，不添加未发生细节。
正文：说明问题表现 → 已尝试的步骤 → 可验证的处理方法 → 适用限制。
结尾：列出还需确认的信息或安全提醒。

## 模板 B：选择清单
标题：购买某类商品前，先核对哪些条件
正文：先列用户需求 → 按尺寸/接口/材料/预算等条件解释 → 给出资料来源 → 提醒不同型号差异。商品作为案例时注明 SKU 和事实来源，不暗示普适结论。

## 模板 C：产品功能介绍
开头：说明商品类别和读者可能关注的问题。
主体：功能是什么 → 如何操作 → 什么条件下可用 → 哪些情况不适用。
结尾：给出说明书、规格或客服查询入口。没有体验时用客观说明，不写第一人称使用感受。

## 模板 D：真实使用记录
只有真实作者完成使用、保存原始记录并同意发布时才能使用。记录日期、样品/SKU、环境、步骤、观察和局限；将“我觉得”与测试事实分开。合作关系按平台要求披露。不用单一体验推断所有用户效果。

## 模板 E：误区澄清
明确待澄清的说法 → 找原始规则或产品证据 → 说明适用范围 → 给读者核验步骤。不要把未经证实的传言复述成事实，不用羞辱或攻击性语言。

发布前将标题、文字、图片和证据一起送审。关联[[小红书内容规范]]、[[商品事实与宣称证据总则]]和[[小红书发布前核验清单]]。

## 真实记录采集卡
作者身份与商品关系：______；样品 SKU/版本：______；收货/体验日期：______；使用环境：______；操作步骤：______；观察到的事实：______；主观感受：______；照片/视频原件：______；不能代表的范围：______；可公开范围和授权期限：______。缺少体验记录时，不选真实使用模板。

## 内容复核
模板的开头、标题和结论要与真实记录对应。个人感受用第一人称表达并注明适用范围，检测结论要独立附证据。不得通过润色把零散观察扩成“长期使用”“大量用户”“普遍有效”。若合作内容由品牌提供脚本，应保留实际作者的审核与表达权，确保披露符合平台要求。
## 体验内容的取证边界
真实场景稿件要能说明作者何时、何地、使用哪个 SKU 完成了什么操作；拍摄素材应来自对应场景，不能把棚拍摆拍包装为长期使用记录。涉及体验感受时明确是个人观察，不把“我觉得方便”扩大为所有人的结果。品牌员工、合作创作者或获得产品/报酬的作者，应先核对账号关系和平台披露要求。

## 模板选择规则
选购清单适合回答可验证的选择条件；使用记录适合展示实际步骤；误区澄清需要可靠资料纠正具体说法；问题说明应提供不依赖购买的解决思路。若内容无法按所选结构兑现标题承诺，退回重选模板。每篇记录目标读者、事实编号、授权、不能代表的范围和评论区可能出现的后续问题。
## 发布前去角色化检查
逐句检查稿件中“我用了、大家都说、回购很多”等经历或群体说法是否有真实记录；无记录则改为中性说明或删去。画面里的居家/办公场景不自动等于真实使用证明，构图、摆放或生成素材都不能替代体验证据。出现品牌合作、样品提供等关系时，按账号实际情况核对披露和脚本审批，保存最终发布版本。
## 原始素材保管
原片与剪辑成片分开保存，登记拍摄日期、作者、商品版本和授权范围。只授权某次笔记的素材不默认加入长期素材库，复用前重新核验许可。
