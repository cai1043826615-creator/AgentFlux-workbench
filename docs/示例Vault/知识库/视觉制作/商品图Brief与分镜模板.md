# 商品图 Brief 与分镜模板

## 任务卡
- 任务编号 / SKU / 变体：
- 平台 / 类目 / 版位 / 画布尺寸：
- 目标人群 / 用户问题 / 浏览场景：
- 本组素材承担的决策任务：
- 核心信息（一句话）：
- 已核验事实与证据路径：
- 使用条件、限制和不可表达内容：
- 产品实拍、品牌资产、授权与来源：
- 参考作品及允许借鉴的具体特征：
- 交付数量、比例、格式、版本和负责人：

素材数量和顺序按具体商品需求调整，不要求固定做满五张。每张画面都应有单一主任务；同一个卖点不要无目的重复。若场景图不是实拍，要确认画面不会让用户误以为包装包含背景道具。

## 生成提示结构
描述产品外观时引用当前 SKU 实拍或准确结构资料；描述构图、镜头、光线、背景、留白和文字安全区；声明不可改变部件和数量；声明禁止擅自生成规格字样、Logo、证书、界面、包装附件。先做无文字视觉，再用批准的真实文案进入设计源文件；不得依赖生成模型正确拼写关键商品信息。

## 评审记录
设计者：______；事实复核：______；渠道复核：______；版本：______；修改说明：______；未解决问题：______。
如存在待核验事实，将该图标为概念稿，不得用于上架。最终按[[视觉制作与质检规范]]进行放行。

## 示例：一个页面如何拆分
画面一负责识别商品，不加未核验的功效；画面二展示已确认的部件或结构；画面三回答一个常见适配问题；画面四显示规格和包装；画面五补充使用步骤或注意事项。若某个问题没有可靠资料，对应画面改为待补，而不是用装饰图凑数。每张图的画面主体、文案和证据要单独成行，方便审核者逐项检查。

## 修改追踪
每轮意见分为事实修订、表达修订、构图修订和渠道适配。事实修订要求回到产品负责人确认，并重审相邻图文；只改构图时仍需检查产品比例和接口；渠道适配要重新核对裁切及限字。保留上一轮评审意见和处理结果，明确“接受/拒绝/待资料”及理由。
## 逐图验收字段
每张图单独填写文件名、目标版位、主信息、事实编号、商品参考来源、实际商品版本、文本校对人、画幅尺寸、裁切安全区、授权状态、缺陷和放行结论。整套图片按用户决策顺序排列，逐张确认没有把同一卖点重复包装成新信息。若生成图出现结构偏差，应修正图像或改用真实产品图，不以小字声明掩盖错误。

## 交付前一致性
将所有导出图与同一版本商品实物、后台属性、活动卡并排核对；对接口、开孔、附件、数量、比例、颜色和文字做逐项检查。重新导出时保留版本号并检查字体嵌入、色彩、压缩、透明边缘和文件损坏。任何一张不合格都阻止整套标记为“可发布”，同时说明可单独使用的已放行资产。
