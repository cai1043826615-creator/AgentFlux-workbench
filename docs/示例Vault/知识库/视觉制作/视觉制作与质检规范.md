# 视觉制作与质检规范

> 版本 1.0 · 复核日期 2026-10-21 · 下一次计划复核 2026-11-21；商品资料、平台规则或生成工具变化时立即复核。

## 目标
让图片、视频封面和详情素材准确展示当前 SKU，帮助用户理解功能、适配和使用方式。视觉不是装饰层：画面会形成商品、效果、规格、配件和使用条件的事实印象，所以每一项可见信息也必须有证据。

## 制作前 Brief
确认任务编号、SKU/变体、目标平台与版位、画布尺寸和安全区域、目标用户、核心问题、主信息、次信息、需要展示的部件、已核验事实、限制/风险、参考素材、授权、品牌视觉资产、交付格式、审核人和版本。明确哪些元素必须原样保留、哪些可调整、哪些不能出现。缺少商品实拍时，合成或生成的视觉必须标为概念稿并审核是否会误认成真实实物。

## 视觉叙事顺序
1. 先让人识别商品和品类。
2. 用一个主视觉表达本屏唯一核心信息。
3. 用真实结构、操作步骤或已核验证据支持信息。
4. 补足适配条件、配件数量、测量范围或活动限制。
5. 让文字在移动屏幕上可读，并与平台版位匹配。

主图承担识别与核心卖点，副图分别解决结构、使用、适配、规格和购买疑问；详情页按用户决策顺序展开。不要把所有信息挤进一张图，也不要让装饰抢占商品辨识度。

## 图像真实性与文本
生成图不得改变商品数量、接口、按键、比例、颜色、标识和包装内容；若工具无法忠实呈现实物，改用已授权实拍或明确标注示意图。图中文字中的数字、认证、功效、价格、品牌和赠品均须复核；小字不能承担重要限制。不得通过遮挡、模糊、透视或装饰隐藏商品差异。

## 质量检查
- 事实：产品外观、规格、卖点、包装和限制正确，证据可回溯。
- 版位：按当前平台后台检查尺寸、裁切、安全区、格式和压缩。
- 可读：缩至真实移动端尺寸后，主信息、数字和限制仍可辨。
- 一致：图中文字与标题、属性、详情、SKU及促销一致。
- 资产：字体、图片、人物、音乐、商标和生成参考均有使用权限。
- 版本：标明文件名、SKU、平台、尺寸、版位、版本、作者和审稿人。
- 交付：附 Brief、源素材、最终文件、事实映射和问题清单。

## 放行流程
设计自检 → 内容/事实复核 → 品牌复核 → 渠道版位预览 → 负责人确认。未解决的事实项、版权项或平台尺寸问题必须阻止放行。修改后重新检查受影响的全部文案和图层；不能因“只改设计”而跳过事实复核。

## 缺陷分级
阻断：产品外形/数量/配件错误，关键参数或认证未经证实，图片容易造成安全/功效误解，素材授权缺失。高优先级：商品结构看不清、主卖点与后台不一致、限制字样不可读、平台裁切遮挡信息。普通：对用户理解影响较小的字体、间距、非核心装饰偏差。阻断和高优先级问题修复后重新验收对应全部尺寸，不用抽样代替逐文件核对。

## 视觉交付记录
交付包应包含源 Brief、商品参考图及来源、每张图的主信息和事实编号、可编辑源文件、导出版本、平台尺寸、授权信息、审核意见和修改记录。最终文件名写明 SKU、渠道、版位、版本及状态。素材存在“示意/渲染/概念”属性时，确保审批者和发布人知道，不误当实物照片。自动生成过程不能省略人工比对。
## 缺陷闭环证据
每个缺陷记录文件名、位置/时间码、严重级别、用户影响、事实或规范依据、修改责任人、修复版本和复验结果。修改文案事实时回到事实卡复核；改结构或重新生成图片时重检商品外观；仅改裁切也要重新检查文字和限制是否仍可见。最终放行由指定审核人对最终文件作出，不以历史版本或生成过程截图代替。
