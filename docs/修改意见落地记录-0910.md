## 注意事项落实

- gpt-taste / Quiet Signal 统一：克制动效（220/300ms 过渡、reduced-motion 关闭）、几何符号无 emoji、QS token（signal 紫/ok 绿/ink 黑/灰描边）
- 参考设计：godui.design/docs/components/layout/stepper（弹簧进度线 + 数字→✓ morph）、21st.dev/@originui/components/stepper/with-mixed-elements（混合元素指示器 + 等分布局）
- 并行开发：6 个 subagent（B1 后端署名+生图失败 / B2 文件接口 / F1 布局+Toast / F2 工位+设置 / F3 详情+状态页 / F4 聊天+svg），文件域互斥，无代码冲突
- 自主验证：typecheck 0 error × 前后端、7 套 smoke 全绿、vite build 通过、浏览器端到端逐条核对（含一次真实任务 #8 全链路：创建→文案→主图→采纳→详情→校对→归档 + 署名气泡 + Toast）

## 过程中发现并修复的问题

1. AgentSettingsModal fileCatalog 类型混乱（API 返回 {id,name} 对象数组、上传 push 字符串）→ 渲染对象崩溃白屏；统一为对象数组，api.ts listFiles/uploadFile 返回类型同步修正
2. approvalQueue 去重只看 taskId → 同任务后续阶段拍板被丢弃；移除条件用决策后 stage 匹配决策前条目 → 旧条目残留；均修复（taskId+stage 双键 / 按 kind 对应阶段移除）
3. 阶段名统一：shared WORKFLOW_STAGE_LABELS「需求对齐」→「需求对接」（对齐参考图）
4. 后端 markIdle 把 activity 固定为「待命」→ 前端与状态 Badge 重复显示；activity 与状态文字相同即隐藏
